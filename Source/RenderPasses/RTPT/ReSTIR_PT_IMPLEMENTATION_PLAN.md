## 1. 目标、范围与完成定义

### 1.1 本轮要完成什么

在现有 ComputePass + RayQuery RTPT 内：
- 保留普通 BSDF 路径、普通 NEE、Light Grid / Tile 和环境采样。
- 将重采样样本统一为到真实 z 的前缀，附带 BSDF 带补偿尾部或 SHaRC 终止类型；显式光照事件先在各自前缀的尾部内组织，再压缩为每像素一个候选。
- 每像素使用一个带根 diffuse / specular（D/S）标签的 reservoir，完成初始选择、时间复用、空间复用。
- 将当前表面信号、路径生成、路径重采样和 NRD 输入合成分开，最后按标签输出，接回已有 NRD 与后处理管线。
- 保留 SHaRC 独立更新 / Resolve / Query，保留 NRD 关闭直通、最终图像独立累积和其余相关模块开关；删除旧 split 及其专用开关。
- 用原始 HDR 等价、运动响应、降噪画质和实际成本证明接入有效。

**实现完成、正确性通过、画质通过、性能值得默认启用是四个不同结论。** 任何阶段只有设计或部分测试通过，都不能替代后续阶段的验收。

### 1.2 明确不纳入本轮

- 不接入 VXPG、PG 短分支、PG 固定终点映射、PG 模型历史、PG 与 BSDF 的 local/suffix MIS。
- 不要求新 GRIS 模式支持 full/local/suffix 配对 SHaRC；原 VXPG 模式的配对实现原样保留。
- 不恢复 ReSTIR DI；Light Grid / Tile 继续服务普通 NEE。
- 不新增第二套 D/S reservoir，不对一个赢家构建跨 D/S 的两套完整概率。
- 不新增独立 U / 尾部 W 历史字段，不要求普通 BSDF 重采样或逐点重追旧尾部。单前缀 W 的剩余补偿由已有尾部 RGB 承担；BSDF 原字段布局可参考，但其数值语义与归一化必须按第 5.2 / 5.3 节适配。
- 不移植或保留旧两 Pass NRD continuation split；其删除纳入阶段 2，具体范围见第 4.4 节。现有单 Pass 积分器保留，用于旧模式和新 GRIS 准备失败时的完整回退。
- 不扩展玻璃、透射、体积、PSR 或所有 Falcor 材质。首批为当前 RTPT 已支持的不透明 / alpha-tested StandardMaterial 反射路径；其中可复用子域仍须验收。
- 不改 DXR RT Pipeline，不修改共享 Material/BSDF、NRDPass、ModulateIllumination、AccumulatePass 等通用实现。
- 不把单个赢家等同于只追一条候选射线，也不预先承诺提速。

### 1.3 VXPG 与新模式的边界

新 GRIS 验收配置使用 guidingMode=BSDF、vxpgEnabled=False。仅切到 BSDF 而仍保留 VXPG 训练，不作为“无 VXPG”成本基线。

未来实现应保留 requested、active、fallbackReason：
- GRIS 关闭：执行既有积分器及其原模式。
- 请求 GRIS，但仍请求 VXPG 引导 / 训练：首版显式报告组合不支持，GRIS 不激活，保留既有模式；不得静默关掉 VXPG。
- 用户通过既有模式和总开关选择无 VXPG 后，才激活满足条件的 GRIS。
- 资源不足或采样前可判定的不支持条件：完整回退到该配置下的原 BSDF 路径，并报告原因。
- 采样后合法 miss、零事件、无效映射：按已定义的事件 / 支持规则处理，不能按亮度补抽或临时切换估计器。

分阶段开发中，尚未支持的组合同样必须显式报告。例如阶段 3–5 使用用户明确配置的 SHaRC off 验收条件；若仍请求缓存查询，不得为了激活新模式而静默关闭 SHaRC，应保留已支持的原路径。

本次已移除旧 split 启动设置，其余既有模块默认配置保持；阶段 2B 的新 DirectSum 路径先以可选模块接入同一主入口，默认关闭。完整新 GRIS 仍在规划中，完成后续验收后再讨论默认启用。VXPG 的回归检查验证移除旧 split 后既有单 Pass 模式正常，不代表验收 GRIS + VXPG。

阶段 2B 必须同时提交两组结果：无 VXPG 的重构路径等价结果，以及 VXPG 等现有渲染模块全部开启的完整管线结果。两组用途不同，均须通过；不能为了满足新 GRIS 范围而在“现有功能全开启”验收中关闭 VXPG。

## 2. 重构前源码事实与起点（2026-10-30 历史快照）

以下保留重构前的只读核对结论，用于说明设计起点；不代表阶段 2A / 2B 后的当前实现。当前删除情况、新 DirectSum 路径及验收状态见文首“当前实施状态与证据”。

### 2.1 普通无 VXPG 路径

- 在 enableNRD=True 模式下，RTPT.cs.slang 在 VXPG 渲染不活跃时调用 RTPTNRD.slang 的 rtptTraceNRD；enableNRD=False 的普通模式调用 rtptTracePath。
- 主表面分别生成 D、S 续接路径；根通道是确定的，没有额外的 1/2 选择概率。
- 后续顶点设为完整 Reflection，通过同一 sg 进行 NEE、BSDF 采样和 RR；没有旧 VXPG 外部均匀 lobe 选择及 rho/invRho。
- 首段 BSDF 射线在 RR 前真实追踪，以获取对应通道距离。更深处续接 BSDF 采样后进行 RR，再追下一段。
- previousDiffuse 来自实际 BSDFSample.lobe，会影响下一命中的 SHaRC footprint 资格。不能因去掉 VXPG 就认为内部采样分支不再影响后续支持。
- 当前 StandardBSDF 连续反射采样的 bs.weight 按所选分支计权并补偿分支选择概率，而 bs.pdf 汇总可用分支的方向密度；两者不能直接解释成同一个分支的 K / bs.pdf。材质内部的分支概率仍存在，不能随外部 PG 概率一起删除。
- 当前 validateScene() 的代码限制为三角形、不透明 / alpha-tested StandardMaterial、无透射和体积；这不是本轮已完成运行验证的声明。

### 2.2 SHaRC

普通路径通过 rtptTrySharcQuery 读取完整 cachedRadiance，贡献为 throughput * cachedRadiance，成功后终止；失败继续真实求值。缓存资格包括深度、前段 delta/diffuse、粗糙度、段长 / footprint、发光与缓存有效性。

usesPairedSharc 依赖 VXPG 模式及其总开关。关闭 VXPG 时已有独立完整 SHaRC 路径；无需把旧 PG 配对权重搬进 GRIS。

### 2.3 Light Grid / Tile

- Tile 只参与主表面、pathDepth=0 的 MAIN_PRIMARY 查询。
- Grid 正常可用时，主表面有有效 Tile 使用 75% Tile + 25% Grid；没有 Tile 使用 Grid。
- 次反弹、训练与 Probe 使用 Grid，不查询主像素 Tile。
- Grid 关闭 / 不可用时回退 Global；环境光仍走 EnvMapSampler。
- samplePdf 是实际采样密度；misReferencePdf 用于 NEE / BSDF 发光命中的互补 MIS。二者不能互换。
- 现有发布分布与下一帧反馈分开。重放、反向评价、候选比较不得重复提交 LocalLights 反馈。

### 2.4 NRD 和后处理

必须区分：
- RTPT.enableNRD=True：生成 D/S 信号、材质因子、距离和 guides；当前约束是 1 spp、accumulate=False。
- NRD.enabled：只控制实际降噪。关闭后仍直通当前帧信号，经 ModulateIllumination 恢复材质。
- FrameAccumulation：独立累积最终 HDR；默认 128 帧、Stop、autoReset=True，0 表示不限帧数。

重构前 rtptTraceNRD 在追踪结束直接写 NRD 纹理，缺少“先完成跨像素重采样，再统一输出信号”的阶段。**这才是本次 NRD 使用方式要重构的核心。**

重构前 nrdSplitEnabled 仅在 VXPG 渲染 active 时实际执行；阶段 2A 已删除该机制。新 GRIS 的 Generate / Temporal / Spatial / Resolve 多 Pass 与其不同：使用独立资源与开关，不依赖旧 split，也不继承 188 B 记录布局。阶段 2B 当前只实现 Generate / Final Resolve 的 DirectSum，尚无重采样。

### 3.2 贡献的唯一归属

设 x 为主表面：

- 相机直接看到的自发光 / 背景：沿用 emission。
- x 上普通 NEE，以及从 x 经 D/S 续接 BSDF 直达发光面 / 环境的互补项：保留于 PT reservoir 外，继续使用一致的 NEE / 命中 MIS。它们不是两份可重复累计的完整直接光；根 delta 的同类事件只归独立 residual 路径。
- x → a → 灯，其中 a 是后续散射顶点：a 的实际 NEE 作为显式光照候选；更深 NEE 同理。
- 经后续散射后才命中发光面 / 环境：按其实际互补 MIS 作为候选。
- x → … → z → SHaRC(z)：z 必须是真实几何命中，完整缓存终止作为一种前缀候选的求值类型。成功查询覆盖的端点光照不再重复执行 NEE / 继续路径。
- 同一可转换分量的 z 由已声明的前缀规则决定，不看将被删除的尾部亮度或缓存成熟度再任意挑点；规则须与旧无 RIS 缓存基线的贡献分区核对。z 前事件独立归属，z 及之后的完整尾部只归属一次；不能把每个深度的完整缓存尾部都当作独立可相加事件。没有合格 z 的事件保留其原所有权 / 明确回退，不伪造端点。
- 根 delta/residual：沿用独立贡献路径。连续 D/S 路径中遇到 delta 时，保留原贡献；可否重放、在哪个连续点连接，依阶段 5 的域定义，不把无法连接解释为整条路径零贡献。
- NRD 深度范围外：最终合成阶段将相应 D/S 光照转入 residual，并执行原距离清理规则；只执行一次。

“直接 / 间接”按实际路径事件及所有权判定，不能只凭一个未经定义的 bounce 数拆 RGB。Tile 留在首表面保留项，不成为本轮 GRIS 灯映射前置条件。

### 3.3 四类状态

- 当前表面状态：主命中身份、材质因子、guides、保留项和 D/S 新鲜首段距离。属于当前像素，不从赢家 / 邻居继承。
- reservoir / 路径状态：根标签、各段采样分支、尾部类型、真实几何与灯样本、前缀重放描述、F、单个前缀 W、M；普通 BSDF 附带已吸收尾部补偿的 RGB、方向和 PDF。有效前缀与有效 / 非零尾部独立标记，不新增 U 字段。详细字段见第 5.4.5 节。独立分配；旧 split 记录删除，不作新路径状态的兼容容器。
- 模型状态：当前帧只读 SHaRC、灯 catalog / Grid 及查询参数。重建缓存事件时从当前 z 查询；不预设旧缓存副本或缓存编号历史，来源权重和支持的有效性另按第 5.5 节验证。
- 输出与历史：NRD 输入、NRD 自有历史、最终累积、GRIS 历史分别管理，不能混用计数或把 NRD / 累积图像当路径样本。

初始可采用未压缩、便于审计的路径记录；每阶段报告 stride × 像素数 × bank 数，以及实际采用的额外表面缓冲、模型资源、临时资源和峰值。不得把论文的单 reservoir 大小当作本项目总显存。

## 4. NRD 重构的固定契约

### 4.1 单 reservoir 输出

保留每个活跃根 D/S 各一条新鲜路径，候选继承根标签，深层 lobe 不改变标签。最终初始化 PT_D=0、PT_S=0：
- D 赢家：PT_D=W*F，PT_S=0。
- S 赢家：PT_D=0，PT_S=W*F。
- 无有效赢家：两项都为零，保留项照常输出。

没有赢得 reservoir 的通道仍保留其直接光、材质因子、当前 guides 和合法首段距离；不按 BRDF 比例把同一赢家 RGB 拆给两路，也不额外除以 2。

此处 W 始终是前缀权重。BSDF 的 F 是使用当前已补偿尾部 RGB 求得的有效贡献，SHaRC 的 F 是当前前缀因子乘当前查询值。第 5.3 节的尾部差额已反映到 BSDF F 后，Final Resolve / NRD Pack 不再次乘该差额、完整 J 或来源分配。F=0 可以是有效前缀的零输出，不等同于无有效前缀。

### 4.2 Final Resolve / Pack 是唯一合成者

~~~text
D = reservedDirectD + PT_D + separatelyOwnedFallbackD
S = reservedDirectS + PT_S + separatelyOwnedFallbackS

若当前表面超出 NRD 范围：
    residual += D + S
    D = S = 0
    按原规则清理距离

noisyColor = emission + D + S + residual
nrdDiffuse = D / currentDiffuseReflectance
nrdSpecular = S / currentSpecularReflectance
~~~

separatelyOwnedFallback 仅表示阶段 1 已明确分区的不可复用贡献，不能用来在看到赢家失败后任意补亮。

保留原反射率下限、镜面材质恢复因子、编码与背景行为。去材质化一次，ModulateIllumination 恢复一次。验证时须区分 FP32 信号恒等式与实际图中的格式转换：

- RTPT 的 D/S 光照输入与材质因子为 FP32。直接用 RTPT 原始输出重建 `emission + nrdDiffuse * currentDiffuseReflectance + nrdSpecular * currentSpecularReflectance + residual`，应与 noisyColor 满足预先固定的严格 FP32 绝对 / 相对容差。
- 现有共享 NRDPass 的 filtered D/S 输出纹理为 **RGBA16Float**；即使 `NRD.enabled=False`，直通 blit 仍写入该 FP16 格式。当前 D3D12 / RTX 5070 后端的实测转换采用 FP16 **round-toward-zero（RTZ，向零舍入）**，不能用 NumPy 默认 float16 最近值转换替代。令 `Q_fp16_RTZ` 表示该显式量化，实际关闭 NRD 与最终累积后的 Modulate 期望值为 `emission + float32(Q_fp16_RTZ(nrdDiffuse)) * currentDiffuseReflectance + float32(Q_fp16_RTZ(nrdSpecular)) * currentSpecularReflectance + residual`；验证先逐位核对实际 filtered D/S 与该转换，再核对材质恢复。其他后端的舍入行为须独立确认，不把本机实测结论扩展为所有设备的保证。
- 实际直通结果相对 noisyColor 的 FP16 量化误差另行报告，不能把该差异当作新增能量项，也不能任意放宽 FP32 等价门限来让检查通过。共享 NRDPass 的格式和实现不修改。

### 4.3 距离、guides 与采样模式

- 首版距离基线是本像素 D/S 新鲜 BSDF 路径各自首段 hitT。无赢家或另一标签获胜不清空合法距离。
- 不用 winner 总路径长、缓存格宽、缓存尾部虚构距离或另一通道距离。
- 距离不乘 W、不除 PDF。miss、无该 lobe、深度越界沿用明确的原规则。
- normal/roughness、viewZ、世界空间运动、反射率均由当前主表面产生。共享几何法线与材质 guide normal 不混淆。
- 新模式仍采用当前组合图的 1 spp、RTPT accumulate=False。NRD.enabled=False 不改变它，也不切换根 D/S 生成方式。
- enableNRD=False 的普通多 spp / 内建累积模式继续保留；首版若请求 GRIS 则明确“不在支持范围”并走原模式，不强行更改用户 spp。
- 距离基线只是假设合理的起点；阶段 8 必须验证其与重采样信号的匹配。若改用经 lobe 接受 / 拒绝的赢家距离，须单独设计和重验，不能直接替换。

### 4.4 删除旧 NRD continuation split

阶段 2A 完成实际删除，不保留禁用占位、隐藏开关或“暂不适用”的旧功能界面。删除范围为：

**精确区分同名机制：RTPT_SHARC_SPLIT_RESOLVE 不在删除范围。** 它用于原 VXPG 配对 SHaRC 的 full/local/suffix Resolve，连同配对缓存和训练语义保留。清理依据 NRD continuation split 的具体符号与依赖，不能按 split 关键词全局删除。

旧 split 专属 188 B 压缩记录及其专属减少重复写入代码随功能删除，不迁移成新的兼容负担；其他活跃路径的主命中复用与减少重复写入优化继续保留，也不重新加入已删除的优化开关。普通单 Pass 是保留的实现，不再标为“旧 split 准备失败回退”；新 GRIS 仍需自己的资源失败回退。

### 4.5 历史重置

GRIS 历史、NRD 历史、FrameAccumulation 分别记录重置原因：
- GRIS / SHaRC / 采样配置等改变信号语义时，处理受影响的 GRIS 历史，并重置 NRD 与最终累积。
- 单前缀 W / 带补偿尾部启用或记录版本变化时，丢弃仅含旧完整事件权重的历史，不能事后由旧 W 和赢家 RGB 反推前缀权重。该格式失效不代表普通相机移动要清空历史。
- NRD 关闭 / 重新开启，重置必要的 NRD 历史与最终累积；仅关闭降噪不要求清空合法 GRIS 历史。
- 相机连续运动使用重投影和局部有效性判断；相机切换、resize、场景结构变化执行明确失效。
- 正常缓存更新不是每帧清空全部历史的理由。
- 最终累积到 128 Stop 后只保持最终图像，上游仍继续；切换模块必须能通过重置立即看见变化。

## 5. 估计器与复用的共同约束

### 5.1 保留 BSDF 分支的权重与缓存事件

本版选定**保留影响后续贡献和截断资格的采样分支**。新鲜候选、无 RIS 新基线、身份重放和固定连接使用同一分支评价契约；不再把“完整 Reflection 的 eval / 混合 PDF”作为所有连续事件的默认替换。

#### 5.1.1 三类概率必须分开

对已核对的 StandardBSDF 连续反射分支，令 l 为实际采样分支：

$$
q_l(\omega)=\alpha_l\,p_l(\omega),\qquad
K_l(\omega)=f_l(\omega)\,|\cos\theta|,\qquad
B_l(\omega)=\frac{K_l(\omega)}{q_l(\omega)}.
$$

- alpha_l 是当前 activeLobes 配置内选择分支 l 的概率；p_l 是选择该分支后的条件方向密度；q_l 是分支与方向的联合密度。K_l 包含该分支的实际材质混合系数及原材质评价约定，不能漏掉系数或再次乘余弦。
- 混合方向密度为 p_mix=sum_l(q_l)。当前 StandardBSDF 的 bs.pdf / evalPdf 对应混合密度，bs.weight 对应实际选中分支的计权；不能把返回的混合 PDF 直接充当 q_l。
- 根 D、S 是分别生成的两个确定通道，根通道选择概率各为 1，不引入 1/2，也不把深层采样分支当成根 NRD 标签。若一个根通道内部仍有更细的随机分支，其概率仍须按真实采样器核对。
- 无 VXPG 模式没有外部 PG / BSDF 提议选择或旧外部 rho；材质内部 alpha_l 继续存在，并已包含于 B_l，不能重复补偿。

路径记录保留分支及其必要辅助随机状态，固定连接时在来源 / 目标各自材质条件下重新求 K_l 和 q_l。只存一个 diffuse / specular 位是否充分，要由实际采样器的所有内部选择证明；其他材质不能直接套用 StandardBSDF 的核对结论。分支不存在、联合密度为零、null / 失败、delta 均有独立处理，禁止用连续除法或概率钳制伪造支持。

适配实现在 RTPT 内，仅读取现有共享 Material/BSDF 接口与实现。现有接口只返回混合 PDF 时，需要在 RTPT 内补齐经过验证的分支评价，不能宣称已有 q_l 接口，也不修改共享材质采样器。NEE / 发光命中的互补 MIS 仍使用原方案规定的密度，不能因为重连需要 q_l 就把其密度一律替换为 q_l。

#### 5.1.2 为什么缓存开启时不能直接边缘化分支

当前 previousDiffuse 取自真实采样分支，决定下一次 SHaRC 查询是否执行额外 footprint 检查。令 E_l(omega) 表示该方向、分支和其余固定状态下允许缓存截断，L_cache 表示恢复材质后的完整缓存辐射值。

当前分支计权的缓存部分期望为：

$$
I_{\rm cache}
=\sum_l\int q_l(\omega)\frac{K_l(\omega)}{q_l(\omega)}
 E_l(\omega)L_{\rm cache}(\omega)\,d\omega
=\sum_l\int K_l(\omega)E_l(\omega)L_{\rm cache}(\omega)\,d\omega.
$$

若保持分支采样及 E_l，却把权重统一改成 K / p_mix，其中 K=sum_l(K_l)，则得到：

$$
I'_{\rm cache}
=\int K(\omega)\sum_l\frac{q_l(\omega)}{p_{\rm mix}(\omega)}
 E_l(\omega)L_{\rm cache}(\omega)\,d\omega.
$$

两式一般不同。失败后的真实续接也服从同一分支分区，因此仅禁止缓存路径的 shift，不能修复已经改变的前向估计器。保留分支评价 B_l 和既有资格规则，是本版保持原缓存估计目标的方案；完整混合 K / p_mix 仅能用于另有证明、下游状态允许边缘化的域，不作为本次默认路径。

#### 5.1.3 缓存终止的唯一贡献

无 PG 的完整缓存命中贡献保持：

$$
C_{\rm cache}=\beta\,L_{\rm cache},
$$

其中 beta 已含沿途实际 BSDF 权重及已经发生的 RR 补偿。成功查询后终止，不在缓存终点重复乘 BSDF、重复做 NEE 或继续追踪；没有 PG MIS，也没有 local / suffix 配对权重。缓存分支按第 5.2 节取 F=C*R_P，R_P 只到 z；前缀 W 承担相应存活补偿，不能再重复除 RR。普通 BSDF 剩余尾部补偿由带补偿尾部 RGB 承担。

根标签、各段分支、previousDiffuse / previousDelta、粗糙度和段长等所需状态在生成与重放中保持一致；固定连接改变几何条件时重新判定资格。SHaRC 材质恢复依赖目标方向，必须在目标条件下求值，不把旧 RGB 当作不变的后缀。

参考实现的 MaterialShading.slang:159–190 提供完整 BSDF 的确定性评价；PathTracer.slang:306–310 则通过 kSeparatePathBSDF 切换到保留分支的 pdfSingle 路径。本版借鉴分支表示和密度区分，不能直接复制其材质、RR 或缓存假设。每个分支的实际频率、联合密度、权重和 null 质量仍须在阶段 3 / 6 验证。

### 5.2 单前缀 W、初始化与零贡献前缀

#### 5.2.1 样本定义与固定记号

持久化的 W 只对应相机 → … → p → z 的前缀；它补偿该前缀的生成、实际已发生的 RR 存活及多轮抽选，不是逐顶点 BSDF 吞吐量。吞吐量、局部 BSDF / PDF 及尾部求值进入 F。两种求值类型共用这个 W：
- BSDFSuffix：保留原 GRIS 尾部字段，rcVertexIrradiance 改为带剩余补偿的 RGB；首次生成仍正常追踪尾部，后续不重追旧尾部。
- SHaRCTerminal：从真实 z 查询当前完整辐射；没有 z 后的方向、PDF、几何或随机流。

本节令 I 为原 BSDF 尾部 RGB，I_tilde 为实际持久化的带补偿尾部 RGB；V 是原完整 BSDF 事件权重，只用于生成时的临时计算、推导与诊断，不存入历史。rho=V/W 也只用于初始化 / 推导，不新增 U、V 或 rho 的独立历史字段。若仍要求 I 数值完全不变，则不能同时只存前缀 W；本版明确允许改变既有尾部 RGB 的数值语义。

令 E_B,t(I) 为原 GRIS 在目标条件下的 BSDF 贡献求值，包含前缀、局部 BSDF/PDF 和实际灯 MIS；有效分支中它对 I 线性。于是：

$$
\widetilde I=\frac VW I,\qquad
\widetilde F_{B,t}=\mathcal E_{B,t}(\widetilde I)
=\frac VW\mathcal E_{B,t}(I),
\qquad
W\widetilde F_{B,t}=V\mathcal E_{B,t}(I).
$$

这是保持完整事件贡献的逐样本恒等式，不是假定前缀 W 与旧尾部独立，也不宣称 I_tilde 单独就是给定 z 的物理辐射或条件无偏积分值。涉及多个线性尾部 RGB 项时，所有实际参与 E_B 的项必须采用同一缩放；非线性截断不能混进此恒等式。

#### 5.2.2 到 z 建立 W，再打包尾部补偿

在前缀到达预定 z、尚未查看尾部结果时，记录实际前缀 RR 存活概率乘积 R_P：

~~~text
W0 = 1 / R_P
缓存成功：F_C = C_cache * R_P；只保留前缀 / SHaRC 类型
普通 BSDF：在该前缀的尾部候选内按原事件选择规则求临时 V0、I0
          I_tilde0 = (V0 / W0) * I0
          写入 W0、I_tilde0、方向 / PDF / 标志；不写入 V0
~~~

原事件选择的局部计算仍可用于得到 V0：令 C_j 为已含实际 BSDF / 灯采样、灯 MIS 和已发生 RR 补偿的事件，R_j 为到事件 j 的累计存活概率。对该前缀内尾部事件：

~~~text
F_j = C_j * R_j
a_j = h(F_j) / R_j
pi_j = a_j / sum(a)
V0 = sum(a) / h(F_selected) = 1 / (R_selected * pi_selected)
I_tilde0 = (V0 / W0) * I0
~~~

h 首版用非负 RGB 的线性亮度；本段的旧 F_j / V0 只是构造完整事件对照。持久化的 BSDF F 随后改为 E_B(I_tilde)，不能继续把旧 F_j 与新的 W 混用。V0/W0 只搬运原完整事件权重中的剩余补偿，不重复计算 I0 内已有的 BSDF、PDF 或 MIS。

R_P 与 R_j 必须服从真实路径时序：首段无前置 RR；z 后实际发生的 RR 只通过尾部补偿进入 I_tilde，不能再加入前缀 W。缓存终止后没有发生的 RR 不得补入。复用时不重新随机杀死旧路径或再次除 RR。

多个前缀初始压缩时，若所选分量原求和系数为 c_k、实际选中概率为 pi_k，则 W'=c_k*W_k/pi_k，I_tilde 不因这次纯选择改变。D/S 是确定生成、待相加的分量，系数各为 1，不额外除 2；若以后增加同量独立估计的平均，才采用其声明的平均系数。完成一次完整像素批次后 M=1，不将尾部事件数、根通道数或成功事件数当作 M 归一化。

#### 5.2.3 有效前缀与尾部非零分开

- 没有合法 z / 前缀 RR 已终止：没有该前缀样本，不重抽。
- 合法到达 z，但尾部全零、尾部 RR 终止或没有非零事件：保留 W0 和前缀身份，I_tilde=0，并标明无有效 BSDF 尾部事件。不可计算 0/0。
- SHaRC 查询成功且 RGB=0：有效零求值，不因亮度为零使前缀身份失效；与缺失 / 未成熟分别处理。
- 对需要保留加权支持的有效前缀，实际抽选必须有正支持。不能继续把“尾部评分为零”等同于“前缀永不入选”；第 5.3 节规定正前缀提议与实际 pi。
- 当前所有物理输出为零时，输出仍可为零，同时存在有效前缀赢家及非零 W；只有无合法前缀时才是空 reservoir。不得为获取非零输出补抽。
- 缓存失败历史本次不贡献，按第 5.4.4 节和 m_P / 支持分配处理；这不同于通过 W=0 任意抹掉有效前缀的来源信息。

本节替代此前 F/U/W 记号及按完整事件权重写回的约定：不新增 U 字段，不直接把旧完整事件 V 当作前缀 W，不原样沿用按尾部亮度清零或 finalize 的旧逻辑。已有旧格式历史须在启用新语义时失效。具体记录见第 5.4.5 节。

#### 5.2.4 推导的适用前提

前缀规则必须在尾部结果之前确定，并与第 3.2 节的贡献所有权一致。完整 BSDF 映射截到 z 后必须与前缀映射相容；不能根据尾部赢家任意更换 z。每个完整候选有效时，其投影前缀及相应 J_P 必须有效。

先在冻结场景、灯分布和缓存 / 已合法条件化状态下验证。旧尾部依赖光照、几何、材质或内部缓存查询；这些依赖变化后，局部 PDF 比不能修复旧尾部 RGB。相关历史失效，由当前新鲜路径补充，不调用完整尾部重追或 traceTemporalUpdate 作为隐式回退。允许恢复必要前缀、检查当前连接，首次新鲜生成尾部仍正常使用 RayQuery。

### 5.3 单前缀 W 与 BSDF 尾部的逐轮递推

#### 5.3.1 前缀域与完整 BSDF 域的分配

保留 Talbot 交叉评价作为完整 BSDF 的参考，不同时引入 Pairwise 的另一套归一化。m_B 表示完整 BSDF 事件域的来源分配，m_P 表示到 z 的前缀域分配；J_B、J_P 分别对应两种映射。它们不是灯采样的 NEE / BSDF MIS。

对同一个目标样本 y，在所使用的域内先做反向映射、支持检查和统一测度评分：

$$
b_i(y)=\eta_i\,\chi_i(y)\,
s_i(T_{t\rightarrow i}(y))\,|J_{t\rightarrow i}(y)|,
\qquad
m_i(y)=\frac{b_i(y)}{\sum_j b_j(y)}.
$$

完整域使用 m_B / J_B / chi_B；前缀域使用 m_P / J_P / chi_P，评分必须定义在相应样本域。前缀分配不把被保留尾部的随机亮度或补偿因子当作已知的前缀边缘 PDF。首个有限验证固定来源系数为 1、已知共同支持，先验证等分情形，再验证两种 m 不同的情形；后续才引入明确的 M 更新 / 上限。

- 对同一个 y，各域分别要求 sum(m)=1；不能比较不同赢家的评分后给所有路径一个全局混合比例。
- 当前新鲜来源参与分母并覆盖复用来源缺失的区域；仅新鲜来源支持时其分配为 1。
- chi_P、chi_B 描述完整生成 / 复用过程及有效映射，不从本次赢家标签、是否有尾部、一次重连是否成功推断整个来源的支持。
- 问题③按第 5.5.4 节选定原版 GRIS 策略：chi 的域约束落实到双向 Shift 的有效性检查与来源项评价中；无效来源项为零后再统一计算 m，不新增通过 W 反推真实赢家 PDF 或遍历全部历史样本的步骤。
- 必须满足 m_B>0 ⇒ m_P>0 及对应投影映射有效。否则单 W 与有限尾部 RGB 无法表示所需贡献；应修正域 / 分配或明确不支持，不能 clamp 分母。
- 源 / 目标概率、分支、几何测度沿用第 5.1 / 5.4 节，不把 RR 比或缓存亮度比当作 J。
- eta / M 只按已声明的分配规则参与；不在选择或输出外重复乘 M，也不再除总 M、邻居数、D/S 路数。

#### 5.3.2 核心更新：一个 W，尾部差额进入 RGB

假设本轮以实际概率 pi_k 选中来源 k。源记录只存 W、I_tilde 及普通 GRIS 尾部字段；V_k 仅为证明中与源记录等价的原完整事件权重。

$$
\boxed{
W'=\frac{m_{P,k}\,W_k\,|J_{P,k}|}{\pi_k}
},
\qquad
\boxed{
\widetilde I'
=\widetilde I_k\,
\frac{m_{B,k}}{m_{P,k}}\,
\frac{|J_{B,k}|}{|J_{P,k}|}
}.
$$

本节固定旧尾部，只作局部重连，因此 I_tilde_k 本身不需要沿尾部重新追踪；局部 BSDF、PDF、可见性和前缀仍按目标条件评价。所有参与 E_B 的尾部 RGB 项统一乘同一个差额。来源 PDF、lightPdf、几何项本身不乘该 RGB 系数。

逐样本验证为：

$$
\begin{aligned}
W'\mathcal E_{B,t}(\widetilde I')
&=\frac{m_{P,k}W_k|J_{P,k}|}{\pi_k}
  \frac{m_{B,k}}{m_{P,k}}
  \frac{|J_{B,k}|}{|J_{P,k}|}
  \frac{V_k}{W_k}\mathcal E_{B,t}(I_k)\\
&=\frac{m_{B,k}V_k|J_{B,k}|}{\pi_k}\,
  \mathcal E_{B,t}(I_k).
\end{aligned}
$$

右侧正是采用同一实际抽选概率的完整 BSDF 事件应有贡献。前缀递推的选择条件期望同时满足：

$$
\mathbb E_{\rm select}[W'g(Y)]
=\sum_i m_{P,i}(Y_i)\,W_i\,|J_{P,i}|\,g(Y_i).
$$

在输入前缀权重有效、各域分配及可逆映射成立时，这两个不变量可以逐轮保持。该证明不依赖前缀与尾部随机选择相互独立；它通过保存原联合贡献的等式避免直接相乘两个任意条件权重。它仍不自动证明动态场景、在线模型和未知支持都满足输入前提。

SHaRC 使用同一个前缀更新 W'，但没有 I_tilde 的差额更新：从当前真实 z 求 F_C，直接用 W'*F_C。由有效 BSDF 前缀转换时丢弃旧尾部负载，不乘 V/W、m_B/m_P 或 J_B/J_P；无前缀权重的旧格式完整事件不得直接转换。

#### 5.3.3 实际选样概率、正支持与操作顺序

旧 GRIS 的完整事件提议可写为 a_B=m_B*h(E_B(I))*V*abs(J_B)。由线性亮度与 I_tilde=(V/W)*I，等价为：

~~~text
a_B = m_B * h(E_B(I_tilde)) * W * abs(J_B)
a_P = m_P * psi(prefix) * W * abs(J_P)
psi(prefix) > 0；首个验证固定为 1
~~~

对同一 BSDF 候选的全部交叉评价，必须使用同一份尚未更新的尾部负载。其共同正缩放在 Talbot 评分比中抵消；存储的 F、来源 self 项和反向项也必须一致缩放，不能混用原 RGB / 已补偿 RGB。该兼容性依赖线性亮度，零缩放与无支持按独立分支处理，不除零。

用于支持验收的明确提议为：固定 epsilon=0.1（仅作为首个数学 / 诊断夹具），分别归一化光照提议 a_R 与前缀提议 a_P：

~~~text
q_P(i) = a_P(i) / sum(a_P)
q_R(i) = a_R(i) / sum(a_R)
pi_i = (1-epsilon)*q_R(i) + epsilon*q_P(i)
若 sum(a_R)=0 且有有效前缀：pi_i=q_P(i)
无有效前缀：输出空 reservoir，不重抽
~~~

BSDF 的 a_R 可取 a_B；SHaRC 的 a_R 可取 m_P*h(F_C)*W*abs(J_P)。最终实现可以另选有证据的正提议，但必须使用真正采用的 pi_i 更新 W，不能把提议概率与方向 PDF 混淆。若忽略正支持而直接沿用零亮度剔除，不能通过零到正 / 缓存成熟度验收。

每轮顺序固定：
1. 恢复源与目标前缀、分支、当前 z，独立求 J_P、J_B 和各域支持。
2. 使用输入尾部负载作全部当前 / 反向评价，计算 m_P、m_B、提议分数及真实 pi；没有对应域时按贡献分配处理。
3. 只抽选一次同一个赢家及其完整记录；按第 5.3.2 节同时更新 W 与 BSDF 尾部 RGB。
4. 更新来源 PDF / 几何等元数据；BSDF 的 F'=E_B,t(I_tilde') 必须重算或按同一差额缩放。SHaRC 的 F' 为当前查询贡献。
5. Final Resolve 输出 W'*F'；不再次乘尾部差额或完整 J。各轮使用独立 bank，不重复反馈 / 训练。

不能把旧 finalizeGRIS 的 sum(a_B)/h(F_B) 原样写入新的前缀 W；它对应完整事件的归一化。只有实际 pi 与某个前缀提议严格配套时，才可化简为该前缀提议总分除赢家代理分数。前缀正支持提议存在时，不能因最终物理 F=0 就清掉合法 W。

m_P=0 / J_P 无效的候选不能参与需要该前缀贡献的提议；若同时 m_B=0，可作为零 / 不支持项处理，不计算差额的 0/0。遮挡零贡献、合法零尾部、映射不支持和数值异常分开记录，不按幸存赢家数重归一化。

#### 5.3.4 有限数值夹具与已知范围

夹具的两个前缀 A、B 分别有尾部事件 (2,8)、(6,14)，均为待相加贡献。关闭 RR、局部求值因子与 J 均取 1：
- 初始事件选择分数总和 30；前缀选择概率为 1/3、2/3。
- A 的事件 2 对应原完整 V=15、前缀 W=3，I=2 时 I_tilde=(15/3)*2=10；B 的事件 6 对应 V=5、W=1.5，I_tilde=20。
- 沿 A 的一条示例选择路线：第 1 轮两种分配均为 1/2、实际 pi=0.8，W=1.875，I_tilde=10；第 2 轮分配仍为 1/2、实际 pi=0.25，W=3.75，I_tilde=10。输出 37.5，与等价完整事件 V=18.75 乘原贡献 2 相同。0.8 / 0.25 是该路线的示例提议参数，不由前述亮度自动推出，不能把单条路线输出当作总积分。
- 有限枚举的解析目标：普通 BSDF 事件总和为 30；缓存 A/B 若返回 12/9，转换后的总积分为 21。必须枚举全部输入与选择分支，不能只验赢家路线或偶然相同的亮度。
- 除等分情形外，须分别改变 m_B/m_P、J_B/J_P、实际 pi，并对 RGB 逐分量检查恒等式；各域分配针对同一测试路径形成分区。
- 尾部全零 / 尾部 RR 死亡仍保留有效前缀；前缀 RR 未到达 z 则没有该样本。空样本不得补抽。

本节提供适配公式与解析验收目标；本对话的内存中有限枚举核算不是仓库正式测试、GPU 渲染证据或阶段通过记录。实际验收见阶段 4–7 和第 7.2.1 节。

### 5.4 连接、灯与缓存

#### 5.4.1 问题①的确定方案：z 终止、不保留尾部及 J 推导

**用户确定的表示：相机 → … → p → z → 当前 SHaRC，路径在 z 结束。** 这里解决的是缓存终止事件的记录方式、方向评价与重连 Jacobian：没有 z 之后的 BSDF 采样事件，不记录其后缀顶点、方向、采样 PDF 或尾部随机流，不添加虚拟尾端点。此前讨论的“保留尾部随机数 v，再令尾部映射为恒等”不作为本版实施方案。

记录与评价规则：

- 缓存事件保留终止类型、终止深度、z 的真实命中身份，以及恢复到 z 为止的前段所需信息：根标签、实际采样分支、重放状态、来源连接 PDF / 几何项和 F/W/M。p 能由重放恢复时不重复保存；这里不删除前段或其他实际 BSDF 事件本来需要的随机状态。
- 若重连点就是 z，该事件不使用普通 BSDF 后缀的 rcVertexWi，也不把缓存值作为 rcVertexIrradiance 后继续执行 z 处的 BSDF/PDF 公式。共享记录布局可复用存储空间，但必须按终止类型解释，不依赖 z 后的无效字段。
- 若实际重连点在更早的 a，仍需保留 / 重放 a→…→z 这段真实路径，a 的方向与普通散射因子按第 5.4.2 节处理。“不记录后缀”专指 z 之后，不是删除所有重连锚点之后的数据。
- p 变为 p′ 后，以 sd_z.V=normalize(p′-z) 恢复当前着色数据、资格与材质因子，从真实 z 查询当前缓存。对合格的非发光表面，缓存近似的是该观察方向下已经积分过后续入射方向的出射辐射；不需要伪造一个 z→b 来重新采样。

当前贡献写为：

$$
\omega_{o,t}=\frac{p_t-z}{\|p_t-z\|},\qquad
C_t=\beta_t(z)\,\widehat L_{\rm cache}^{\,t}(z,\omega_{o,t}),\qquad
F_t=C_tR_t.
$$

beta_t 包含实际前段的 BSDF 权重和已发生的 RR 补偿；此处 R_t 即到 z 的 R_P,t，缓存 F 与持久化的前缀 W 按第 5.2 节分工，不新增 U。z 处材质恢复对观察方向的响应进入当前贡献 F，不是额外的 BSDF 比、缓存亮度比或 Jacobian。BSDF → SHaRC 转换仅适用于已按第 5.2 / 5.3 节建立有效前缀权重的记录。

**当前缓存的方向精度边界：**RTPT 当前启用 SHARC_MATERIAL_DEMODULATION、关闭 SHARC_ENABLE_SH_ENCODING。rtptSharcMaterialFactor 使用当前 sd.V 计算 NdotV，并以 diffuse albedo + approxSpecularIntegralGGX 等因子恢复缓存；查询返回值已包含这次恢复。该近似不能重建缓存未保存的完整方向光照分布，不能宣称与逐方向 BSDF 后缀求值完全等价。本项不更改方向编码配置；GRIS 接入误差与缓存自身的方向近似误差分别验收。

**直接重连 z 的 J：**先限定在固定几何、已验证的可逆连续采样图表中。来源末段为 p_s→z，目标末段为 p_t→z，保持该段分支 l，并令：

$$
\omega_s=\frac{z-p_s}{\|z-p_s\|},\quad
\omega_t=\frac{z-p_t}{\|z-p_t\|},\quad
G_s=\frac{|n_z^{geo}\cdot(-\omega_s)|}{\|z-p_s\|^2},\quad
G_t=\frac{|n_z^{geo}\cdot(-\omega_t)|}{\|z-p_t\|^2}.
$$

G 只使用几何法线。对分支选择随机数，保持其在所选概率区间内的相对位置；对方向随机数，将源、目标统一换成 z 的面积坐标。其余真实保留前段及分支中保持不变的辅助坐标记为 v_pre；它不表示 z 后的尾部随机数：

$$
du_s=q_{s,l}(\omega_s)G_s\,dA_z\,dv_{\rm pre},\qquad
du_t=q_{t,l}(\omega_t)G_t\,dA_z\,dv_{\rm pre}.
$$

于是来源到目标的 Jacobian 为：

$$
\boxed{
J_{s\rightarrow t}
=\left|\frac{\partial u_t}{\partial u_s}\right|
=\frac{q_{t,l}(\omega_t)}{q_{s,l}(\omega_s)}
 \frac{G_t}{G_s}
=\frac{\alpha_{t,l}p_{t,l}(\omega_t)}
       {\alpha_{s,l}p_{s,l}(\omega_s)}
 \frac{G_t}{G_s}.
}
$$

q_s、q_t 都是在各自前一点 p_s / p_t 采到 z 的分支联合密度。该密度比包含内部 alpha 的变化，不含外部 PG 概率。z 已经终止，没有从 z 继续采样的方向，因此**不能再乘 z 处的出射 BSDF PDF 比值，也不能再乘 z 处的 BSDF**。这不是假设某个 z 出射 PDF 等于 1，而是该采样事件不存在。

用户所说“J 只计算 z 前面变更的点”，具体指真实保留路径中受映射影响的采样和连接；即使 z 的位置不变，p→p′ 也可能改变连接距离和 z 处的入射几何角度，G_t/G_s 仍需计算。若直接连接之外还有前段非恒等变换，须乘其已推导、未重复计入的 Jacobian；若实际锚点位于 z 之前，则按第 5.4.2 节处理，不将所有情况都简化为只算紧邻 z 的一个点。

令 A_t 为到 p_t 采样前、不含 RR 补偿的目标前缀权重，L_cache,t 为目标方向下恢复后的完整缓存辐射值。配套事件评价及一次抵消检查为：

$$
F_t=A_t\frac{K_{t,l}}{q_{t,l}}L_{{\rm cache},t},
\qquad
F_tW_sJ_{s\rightarrow t}
=A_tK_{t,l}L_{{\rm cache},t}W_s
 \frac{G_t}{q_{s,l}G_s}.
$$

目标 q 正好抵消。F_t 已按随机数域计权，不能再额外乘一次 G_t。缓存 F=C*R_P，持久化的 W 是前缀权重；已发生前缀 RR 的补偿由来源权重承接。重评不重新随机杀死该路径，也不额外添加 RR 比或缓存亮度比作为 J。

这只是已声明连续图表的密度推导，不代替实际双射和辅助坐标充分性验证。源 / 目标分支不存在、密度为零、连接不满足条件或目标前缀提前缓存终止时，按映射支持与新鲜来源覆盖处理；禁止直接 clamp J 来掩盖问题。几何运动、变形或面积改变须另推相应映射，不能无条件沿用固定几何公式。

**设计与验收边界：**问题①的终点表示和 J_P 已确定；问题②采用第 5.2 / 5.3 节的单前缀 W 与带补偿 BSDF 尾部递推。已有新格式 BSDF 记录转换时保持其有效前缀 W，丢开旧尾部负载，查询当前 SHaRC；不能把只有旧完整 V 的记录当作可转换前缀。两项均尚待阶段 3–7 实现和验收。局部 J 可计算与有限贡献恒等式不替代问题③的支持 / 分配或问题④的在线条件证明，不恢复强制旧缓存快照。

#### 5.4.2 缓存之前的普通锚点与 Hybrid

若重连点 a 仍需沿固定后缀 a→b→…→y 继续，a 的入射方向变化会改变它采样既定出射方向的密度。保持其分支和相应辅助坐标、其余坐标确实不变时：

$$
J_{s\rightarrow t}
=\frac{G_t}{G_s}
 \frac{q_{c,t}}{q_{c,s}}
 \frac{q_{a,t}}{q_{a,s}}.
$$

这里 G 对应 c→a；固定 a、b 的后续几何项抵消。若还有非恒等坐标变换，须继续乘其已推导的 Jacobian。Hybrid 保持前缀随机数坐标不变时该部分为 1，但前缀贡献和实际接缝仍需重新评价，不能把整个 Hybrid 都当成 J=1。

参考 Shift.slang:461–482 先计算几何比和连接前 PDF 比，再在需要保留出射采样的普通锚点处加入相应 PDF 比（498–541）。本版用已验证的分支 q 对应这些密度：普通 BSDF 完整映射使用 J_B；截到指定 z 的投影使用 J_P，两者差额按第 5.3.2 节进入尾部 RGB。在缓存 z 之前的真实普通锚点仍属于保留前缀，其适用因子不能删掉；缓存终点自身只采用第 5.4.1 节的终止形式。

#### 5.4.3 灯样本和缓存的其他约束

先验证固定真实顶点重连，再验证 Hybrid：
- 重放目标前缀，连接保存的真实锚点；连接处重新求材质、可见性、PDF 与贡献。
- 只在已证明的连续图表中使用几何项与实际采样密度比构造 J。几何面积转换使用几何法线；不可把光照比、RR 比当作 J。
- 恒等重放的随机数与强制保持同一几何 / 灯点是不同映射，不把两套修正重复相乘。
- 固定后缀只有在其依赖确实不变且因子分解成立时才能复用贡献因子；不是保存任意旧 RGB。普通 BSDF 只读保存方向、PDF、事件信息与带补偿 RGB，局部更新 p / z 的 BSDF/PDF 并检查连接；首次生成后的复用不执行 z 后完整路径重放、新尾部采样或 traceTemporalUpdate。Hybrid 允许恢复必要前缀，不把前缀射线与尾部重追混淆。
- 尾部所依赖的几何、材质、光照或内部缓存 / 灯模型改变时，按版本 / 有效性规则丢弃受影响历史，由新鲜来源覆盖，不以局部 PDF 比冒充尾部当前光照，不通过重追尾部绕过本版约束。首批先验证固定世界和普通相机移动。
- 现有 Tile 不进入间接查询。Grid 同帧冻结、采光位置与查询上下文完全不变时，可验证保持原灯样本的简化；采光点、类别概率、Grid / catalog 或灯几何变化时须重评相应密度与映射。
- 同一灯多来源的边缘 PMF 不自动等于已实现可逆采样映射；保留分支辅助状态或证明边缘表示充分，不能凭概率数值直接宣称有双射。
- 面积灯、解析 delta 灯、环境分别使用正确的面积 / 离散 / 方向测度；不对 delta 的零方向 PDF 做除法。
- SHaRC 候选保存真实终点身份；缓存格和槽号仅为查询辅助。其函数是当前缓存近似，不能虚构缓存尾部路径。
- 历史缓存事件当前失效时，不临时改成普通 NEE / 继续路径后沿用来源 W。

#### 5.4.4 从真实终点 z 查询当前 SHaRC：重建、转换与失败契约

z 专指最终缓存表面，p 为其前一顶点。若重连锚点更早，锚点到 z 仍是实际保留 / 恢复的前缀；缓存 z 后没有需要生成、记录或追踪的尾部。SHaRC 查询近似当前方向下完整的出射辐射，不是给 rcVertexIrradiance 填 RGB 后继续执行普通 z BSDF/PDF 公式。

路径保存 SHaRC 终止类型、深度、真实表面身份及必要前缀信息。缓存 key / slot 不作为身份；已有 GRIS 命中和重放数据足以恢复时不重复存 p / z 世界坐标。详细字段见第 5.4.5 节。

重建顺序固定为：
1. 恢复当前前缀、p、z 和分支，检查指定 z 与贡献所有权。前缀若应在更早位置终止，不能跳过该事件强接旧 z。
2. 用 RayQuery 检查 p→z 及该映射必需的前缀 / 接缝可见性；不逐点重追 z 后旧尾部。
3. 以当前条件执行等价于 rtptTrySharcQuery 的深度、previousDelta / previousDiffuse、粗糙度、段长 / footprint、发光和材质检查。
4. 以 sd_z.V=normalize(p'-z) 恢复当前材质因子，从真实 z 查询本帧只读 SHaRC，检查条目存在、成熟度及数值有效性。Generate、交叉评价、shift 与 Final Resolve 读取同一版本。
5. 成功时 F_C=A_t*L_cache,t，J_C=J_P；A_t 是按第 5.2 节处理的前缀因子。来源 W 始终是前缀权重；用真实 pi 按第 5.3 节更新。
6. 已有新格式 BSDF 前缀可在此切换为 SHaRC：不读取其带补偿尾部 RGB，不乘原 V/W、m_B/m_P、J_B/J_P，不增加 z 处的 BSDF、方向 PDF 或其比值。W 不因类型转换而重新初始化为 1 或当前逆 PDF。
7. 仅含旧完整事件权重的历史不能这样转换；启用新格式时失效，不以旧 / 新亮度比例补救。缓存成功后 z 处不再执行 NEE、BSDF 或 RR。

内部结果独立分类：
- geometryUnavailable / mappingUnsupported：所需几何、前缀或分支不可恢复；该映射不支持，按 chi_P / 来源分配处理。
- segmentOccluded：当前贡献 F=0，可归入用户可见的重建失败统计，但不能因此断言几何 J 必然不存在或随意修改整个来源的支持。
- cacheIneligible / cacheMissing / cacheImmature：该缓存终止当前不成立，历史候选本次不产生缓存复用贡献。真实续接由当前新鲜路径按既定所有权生成。
- cacheZeroValid：查询成功但 RGB=0，是有效零求值；物理亮度提议可以为零，正前缀提议仍可保留该有效前缀与非零 W，输出为零，不重抽。
- numericInvalid：非有限值或非法负值单独报告，不能当作普通零贡献通过验收。

“失败后为零”指本次复用贡献 / 对应竞争项，不是看到 F=0 就把合法前缀 W 改成 0。几何无效时标无效；资格 / 缓存失败历史按同一路径上的 chi_P、m_P 和新鲜覆盖停止该来源的缓存贡献。不能丢弃失败赢家后按幸存数重新平均，也不能保留错误分母。新鲜路径缓存查询失败继续原 BSDF；历史缓存失败不使用旧缓存 RGB、不临时延长旧尾部、不补抽到成功，也不从 SHaRC 历史凭空恢复 BSDF 尾部。

上述分类由第 5.5.4 节的 Shift / 来源项契约接入 m 的计算。映射不支持、物理遮挡零贡献、合法黑色缓存与数值异常分别处理；不能把所有零值都改成 chi_P=0，也不能只丢弃失败历史候选，却在当前候选的交叉分母中继续计入同一路径上失效的历史项。

#### 5.4.5 持久化字段：一个前缀头，两种尾部类型

以下是未来布局的语义要求，不是固定 stride / 位域，也不继承已删除 split 的 188 B 记录。U、V、rho 不成为新增持久化字段；V 与 rho 只在初始化 / 数学诊断中临时使用。

两类共用的前缀头：
- W：唯一的前缀贡献权重；M：已声明的生成批次 / 来源分配元数据；F：与当前记录语义一致的有效贡献 / target 缓存。BSDF F 使用带补偿尾部，SHaRC F 使用当前查询值；F 不是可回退使用的旧 SHaRC 快照。
- 真实 z 的 TriMeshHitInfo 类身份：实例、primitive、重心坐标。位置、法线、材质及 p 能恢复则不重复存；不能用缓存格中心替代真实命中。
- 根 D/S、实际采样分支、深度 / 指定前缀终点、终止 / 尾部类型与必要的 previousDiffuse / previousDelta 等状态。
- 前缀 init seed / checkpoint、必要采样状态及来源上下文引用，使当前 p、z、分支与资格可按映射恢复。像素 / 样本索引或来源相机资源已有隐式定位时复用。
- 来源连接的分支联合 PDF、几何项和其他非恒等前缀 Jacobian 信息，例如原 cachedJacobian.x / z 对应的数据。只保留实际需要的信息，不以整个旧 SHaRC / 旧场景快照代替可执行恢复定义。
- 有效前缀、有效尾部、尾部零 / 缺失与数值错误分别标记。历史格式、场景 / 模型依赖版本可由帧级资源统一管理，不要求每条重复大块状态。

BSDFSuffix 负载：
- rcVertexWi：真实 z→b 方向，继续用于当前 BSDF/PDF 评价。
- rcVertexIrradiance 等实际参与 E_B 的线性尾部 RGB：存 I_tilde，并在每轮按第 5.3.2 节统一缩放。
- 来源 z 出射 PDF（例如 cachedJacobian.y）、lightPdf、NEE / 光源类型、路径长度、分支与事件标志；数值仍是其真实 PDF / 类型，不随 RGB 缩放。
- 原布局中的尾部 seed 可作为未使用兼容槽保留，但本版复用不依赖它、不执行尾部随机重放。不能误删用于恢复保留前缀的 seed。

SHaRCTerminal 负载：
- 类型表明在真实 z 终止；其余所需数据均来自前缀头，无额外方向或尾部 RGB 负载。
- 不需要 rcVertexWi、I_tilde、z 出射 PDF、尾部 lightPdf、尾部顶点或尾部随机流；共享布局中的这些槽位必须在该类型下不读、不影响结果。
- 不保存永久缓存编号、旧 key / slot 或额外旧缓存 RGB。当前查询用真实 z、当前法线、材质及 z→p' 方向重新构造 SharcHitData。
- SHaRC 内部样本数 / 成熟度属于当前模型查询，不能当作 reservoir M 或额外 W。

同一输入候选的前缀头与尾部必须一起选中、一起更新，禁止 W 来自一个赢家而尾部来自另一个赢家。F、PDF / 几何缓存及类型切换必须与更新后的负载一致；格式变化清空旧语义历史。

### 5.5 跨帧分配：原版核对与当前 SHaRC 适配

#### 5.5.1 两个来源、两种域与逐路径分配

C 是当前新鲜来源，H 是历史来源；除下一节的原版对照外，持久化 W 均指前缀权重，SHaRC 的 J_H 均为 abs(J_P,H→C)。对同一个当前域前缀 y：

$$
B_C(y)=\eta_C P_C(y),\qquad
B_H(y)=\eta_H\chi_{P,H}(y)
P_H(T_{C\rightarrow H}(y))|J_{P,C\rightarrow H}(y)|,
$$

$$
m_{P,C}(y)=\frac{B_C(y)}{B_C(y)+B_H(y)},\qquad
m_{P,H}(y)=\frac{B_H(y)}{B_C(y)+B_H(y)}.
$$

本节 P_C / P_H 是代理评分，区别于第 5.2 节的前缀样本。评分及分母必须在同一路径 y 上一致；实际 m_C(y_C)、m_H(y_H) 对应不同候选，不能要求二者相加为 1。eta 按已声明的来源批次 / M 规则使用；原版 history M 的上限不等于 W 的上限，也不使相关历史变为独立样本数。

普通 BSDF 仍另算完整事件的 m_B 与 J_B，随后通过第 5.3.2 节的差额进入尾部 RGB。不能只因都叫 target，就把带随机尾部补偿的 BSDF F 当作前缀函数；不能从本次赢家尾部类型推断整个来源的加权覆盖。

#### 5.5.2 本地参考代码实际计算了什么

以下仅记录原完整事件版本的 Talbot 行为，用 V 表示原 PathReservoir.weight 的完整事件权重，原 F 表示其未作本项目尾部打包的贡献；它不是新单前缀 W 的直接实现。

历史候选的分配为：

$$
m_H(y_H)=
\frac{\eta_H h(F_H^{stored}(X_H))/J_H}
{\eta_C h(F_C(y_H))+\eta_H h(F_H^{stored}(X_H))/J_H}.
$$

当前候选的分配为：

$$
m_C(y_C)=
\frac{\eta_C h(F_C(y_C))}
{\eta_C h(F_C(y_C))
+\eta_H h(F_{H\leftarrow C}^{eval}(T_{C\rightarrow H}(y_C)))
|J_{C\rightarrow H}(y_C)|}.
$$

TemporalReuse.cs.slang:139 限制历史 M；174–175 映射历史候选，184–193 形成当前 / 来源 self 项，206–209 反向评价，214–224 用 p_self/p_sum 合并并 finalizeGRIS。原完整事件提议为 m*h(F_target)*V*abs(J)，其纯提议归一化可写为 sum(score)/h(F_winner)，不另除总 M。

#### 5.5.3 无旧缓存数值：统一当前代理与实际 pi

目标 F_C^t(y) 从当前真实 z 查询。反向到来源几何 / 采样上下文后，仍查询本帧只读缓存，得到 tilde F_H^t(x)；它只作为当前代理，不冒充当时生成历史样本的旧 target，也不重生成来源 W。第 5.5.6 节采用合法前缀上严格为正的分配代理，作为 m_B>0 时 m_P>0 的充分条件；仅在抽选 pi 中添加正提议不保证该条件。令 ell_i 为当前查询可用时的非负缓存贡献亮度，缺失时仅在代理中取 0；L0>0 为本轮固定的亮度尺度，首个支持证明直接采用 P_i=1。引入缓存评分时使用：

$$
\ell_i^t=
\begin{cases}
h(F_{S,i}^t),&\text{当前缓存查询合法成功},\\
0,&\text{当前缓存查询不可用},
\end{cases}
\qquad P_i^t=1+\ell_i^t/L_0>0,\quad i\in\{C,H\}.
$$

F_S,i^t 专指从各侧真实 z / 方向求得的当前缓存贡献，不读取随机带补偿 BSDF 尾部；数值异常仍须单独报告，不能当作普通不可用通过验收。将代理代入第 5.5.1 节的 B_C、B_H、m_P。历史项同样重评为 eta_H*chi_P,H*P_H^t(X_H)/J_P,H→C，不能一边沿用旧 target，一边反向使用新代理。对同一 y，旧历史项为 4、新历史项为 2、当前项为 1 时，错误混用给出 4/5+1/3=17/15；统一后为 2/3+1/3=1。这里 4 / 2 / 1 表示包含 eta / J 后的完整来源评分项。正值底项只影响 m_P 的分配，不加进物理 F，不伪造缓存成功，也不改变缓存近似目标。

h(F_C)=0 时，物理光照提议为零；有效前缀仍由第 5.3.3 节的正 psi 提议保留，不能据此把前缀 W 置零或假定历史支持消失。首个验证以 psi=1、明确支持分区开始，再验证统一当前缓存代理。

缓存亮度提议为：

$$
s_C=m_{P,C}(y_C)h(F_C^t(y_C))W_C,\qquad
s_H=m_{P,H}(y_H)h(F_C^t(y_H))W_H J_{P,H\rightarrow C}.
$$

本版使用包含正前缀提议的实际 pi_C / pi_H。赢家 k 的写回为：

$$
W_{out}=\frac{m_{P,k}(y_k)W_kJ_{P,k}}{\pi_k},
\qquad
\widehat I=W_{out}F_C^t(y_k).
$$

仅在分数非零、支持有效且实际 pi 恰为 s_i/sum(s) 时，才退化为旧 sum(s)/h(F_winner)。两项物理亮度都为零时仍可能存在有效零前缀赢家；无合法前缀才是空集合。无额外旧 / 新亮度比、不重复 M，也不在 SHaRC 类型上乘 BSDF 尾部差额。

若来源前缀贡献权重在所条件化状态下有效、映射可逆、chi 不越过实际支持，且对同一 y 的 m_P 形成分区，则：

$$
\mathbb E[\widehat I_t]
=\int m_{P,C}^t(y)F_C^t(y)\,dy
+\int m_{P,H}^t(y)F_C^t(y)\,dy
=\int F_C^t(y)\,dy.
$$

更换一致代理不要求知道真实赢家 PDF，但当前查询成功、两个分母数值相等或 sum(m)=1 均不能单独证明来源权重有效。BSDF 的完整事件不变量另由第 5.3.2 节保持，不用缓存评分替代其缺失的尾部补偿。

#### 5.5.4 问题③的确定策略：有效域 Shift、交叉评价与 Talbot 分配

**用户决定：BSDF + SHaRC 复用采用原版 GRIS 的这一策略。** GRIS 第 35 式只在来源样本的有效映射范围内定义非零来源代理项，范围外为零；第 36 式再按各来源代理项的比例分配 m。chi_P / chi_B 是该域约束的显式记号，实现时融入 Shift 的有效性检查与来源项求值，不是另行遍历历史样本或从 W 推算真实赢家 PDF 的算法。原版输入贡献权重有效、源域明确和映射合法的前提仍须满足，不能因选择同一框架就省略 SHaRC 的适配与验证。

**两种域分别计算。** 令 D 为前缀域 P 或完整 BSDF 事件域 B，S_D,i 为来源 i 在该域内已声明且有效计权的生成 / 复用支持，T_D,i 为其到当前域的有效 Shift。对同一个当前域候选 y：

$$
b_{D,i}(y)=
\begin{cases}
\eta_i P_{D,i}(T_{D,i}^{-1}(y))\,|J_{D,i}^{-1}(y)|,
& y\in T_{D,i}(S_{D,i}),\\
0,&\text{otherwise},
\end{cases}
\qquad
m_{D,i}(y)=\frac{b_{D,i}(y)}{\sum_j b_{D,j}(y)}.
$$

eta 按第 5.5.1 节的来源批次 / M 约定使用，不重复进入 W 或输出归一化。P 域先用正的常量代理验证支持，再按第 5.5.3 节验证带正值底项的统一当前缓存代理；不能把 BSDF 的随机带补偿尾部亮度当作前缀边缘 PDF。B 域对同一候选使用同一份输入尾部负载作 Talbot 交叉评价。若某域存在合法支持来源但代理分母为零，则对该域 / 同一 y 的所有来源统一改用正的常量代理，保留 eta / 反向 J / 有效域因子重算 m；不能仅修补赢家项或用正抽选概率 pi 掩盖未定义的 m。只有全零分母时回退仍不够：个别来源 m_P=0 而 m_B>0 也破坏单 W，须按第 5.5.6 节在整个合法前缀支持上保持代理正值。无合法支持来源则按该域的空 / 不支持项处理，不计算 0/0。实际抽选继续遵守第 5.3.3 节的正前缀提议规则。

**每个来源项的处理顺序：**

1. 选定被评价的同一条候选 y 和域 D，使用该来源的几何 / 相机 / 采样上下文恢复必要前缀；self 项与交叉项遵守同一域定义。不得用该来源当前赢家的类型或尾部，替换被评价候选的身份与负载。
2. 检查来源权重格式、声明的源域及依赖有效性；检查正反映射相容、指定 z、分支及联合密度、深度、连接条件和必需的可见性。缓存的资格、提前终止和失败后 BSDF 续接均属于生成规则，不能跳过更早应发生的终止事件强接旧 z。所需射线统一使用 RayQuery。
3. 映射不支持或必要来源状态不可恢复时，该来源在这个 y 上的有效域项为零，并记录原因；同一 y 的来源 self / 交叉评价必须采用相同判定。当前新鲜来源覆盖缺失区域，只有该来源支持时其分配为 1；不得仅按幸存候选数重新平均。
4. 合法 SHaRC 前缀从真实 z 按各侧 z→p 方向重新判定资格、恢复材质并查询同一版本的本帧只读缓存。两侧均按第 5.5.3 节重评代理，不混用旧缓存 RGB / 旧 target，不重新生成来源 W。当前代理可计算不代表历史域已经成立；源域或终止规则的必要状态无法确认时，采用第 3 步的保守处理。
5. 缓存缺失、未成熟或资格失败时，本次不产生该缓存终止的复用贡献，配套处理同一路径上的来源分配；新鲜路径按原规则生成 BSDF 回退。历史 SHaRC 记录没有 z 后的后缀，不临时延长、重追或补抽。合法黑色缓存与遮挡零贡献按第 5.4.4 节单独分类，不因 F=0 任意清除有效前缀 W / chi_P；第 5.3.3 节正前缀提议继续保留所需支持。
6. 在完成有效域与代理项求值后计算 m_P / m_B，再计算实际抽选概率 pi；只抽选一次同一赢家。用第 5.3 节公式更新前缀 W 和 BSDF 尾部 RGB；SHaRC 只用前缀递推与当前查询贡献，不原样套用原完整事件 finalizeGRIS。

**Shift 的前缀 / 后缀边界：**“反向”表示当前候选映射到来源上下文，不是从光源反向追踪整条路径。Shift 数学上作用于相应域中的样本；在采用的 Reconnection / Hybrid 中，恢复相机侧前缀并重连保存的真实锚点。普通 BSDF 保留锚点后的后缀几何 / 负载，重新评价变化接缝的 BSDF / PDF 并计算 J_B；本项目不执行旧尾部重追。SHaRC 终止于 z，只处理到 z 的真实前缀及 J_P，没有 z 后的方向、PDF、几何或随机流。若锚点在更早的 a，a→…→z 仍须正确恢复 / 保留，不能误删这段真实路径；也不能假定其全部 Jacobian 恒为 1。

**必须保留的支持反例与适配验收：**

- 历史仅覆盖 A，新鲜来源覆盖 A/B，当前两类贡献各为 1。A 上可以等分；B 上历史项为零、新鲜分配为 1，正确期望为 2。全域各分一半得到的 1.5 必须被测试检出，不能因实际历史赢家重建成功就跳过。
- 在 eta=J=1 的简单夹具中，合法来源评分为当前 2 / 历史 6 时 m_C=1/4；历史映射域不成立时，其项为 0，m_C=1。无效来源项须同时从对应的 self / 交叉分母中排除，而非只丢弃失败历史候选。
- 到 z 注册 W 与零尾部正提议已确定；须验证零尾部、尾部 RR 死亡及黑色缓存仍有正确前缀加权覆盖。缓存成熟前的普通 BSDF 回退可能覆盖同一前缀，不能仅因“以前未成熟”排除；仅持有旧完整 V 的记录仍不能直接继承。
- chi_B 必须依据来源完整生成 / 复用过程的联合覆盖，不以当前赢家是 SHaRC 就断言整个来源没有 BSDF 支持。只有 SHaRC 负载的具体历史记录也不能凭空提供缺失后缀。m_P 与 m_B 不同的情形须连同尾部差额、非单位 J 和至少两轮递推一起验收。

**状态与剩余关口：**问题③不再列为尚待选择处理策略；其有效域、来源项和失败分配采用本节方案。尚待落实每种支持图表与必要来源状态 / 失效规则，验证其足以判断来源域，并完成阶段 5–7 的正反映射、双域分区和多轮贡献验收。版本信息必须说明能保证哪些规则不变；当前缓存查询成功、两个分母相同或 sum(m)=1 均不能单独替代这些证据。不要求保存整份旧缓存，也不能把所有帧都退回 fresh-only 冒充时间复用已通过。

#### 5.5.5 问题④另行验证：在线模型与历史权重依赖

问题③确定上述分配策略，不等于问题④已经解决。在线 SHaRC、Grid / Tile 反馈与历史样本的依赖仍须满足合法条件化权重要求；Shift 可逆、独立 seed 和 GPU barrier 均非单独证明。尾部依赖或必要来源状态变化时采用明确失效，不启用尾部重追绕过约束。按阶段 7 先冻结状态，再只改变缓存非零值且保持支持，最后验证零到正、成熟度、LOD / 槽回收和运动改变支持；问题③的域检查与问题④的在线依赖分别留证，不强制旧缓存快照。

#### 5.5.6 问题③的条件推导、正支持修正与信息边界

本节是沿已选 GRIS 策略补充的项目推导。结论限定在明确的贡献归属、有效源权重和可逆连续图表内；先固定场景、材质、灯模型、查询规则及独立只读缓存状态。允许推广到合法条件化的上下文，但不直接把任意历史依赖状态视为可条件化。首个证明的 eta 为固定正数；带随机依赖的 M / 支持状态或在线训练仍须核对其条件。以下公式不构成已实施或渲染通过记录。

**A. 给出一种可分析的选点规则。** 令 u 表示完整的到 z 前缀描述，包含根通道、采样分支、必要辅助随机数和几何身份，不只是顶点位置。令 Q_i(v) 为来源上下文 i 中的结构资格：深度、粗糙度、previousDelta / previousDiffuse、段长 / footprint、非发光等，参考 rtptTrySharcQuery 在实际缓存查找前的检查；启用 / Use cache 状态、缓存条目存在性、成熟度和缓存 RGB 不用于选点。首个可分析规则取 z 为真实路径上第一个 Q_i(v)=1 的表面。

这样 z 前的顶点在该上下文中均不具备查询资格，不会因缓存内容变化而提前缓存终止。到 z 时先登记前缀 W，再查询缓存或生成普通续接。源 / 目标重放后须分别检查保存的 z 仍符合这条首次资格规则，不能跳过新出现的更早资格点。几何、采样分支、RR 正存活支持、max depth 和普通积分器确定性终止仍限制前缀域；Q 的 LOD / 网格参数属于须已知的规则状态，不能当作与相机无关。

该规则是本次推导使用的具体收窄，不声称现有 Generate 已实现。只有实际在该 z 成功查询的 SHaRCTerminal 才在 z 结束且没有 z 后负载。z 查询失败后，后续 NEE、BSDF 与可能的更深缓存查询必须仍按原积分器生成，其剩余贡献只归所属尾部分量一次；若作为 BSDFSuffix 内部尾部，其实际缓存 / 灯模型依赖也须登记和保护。若选择对更深终点另建缓存记录，则须另给唯一分量归属和有效前缀权重，不能与前述完整尾部重复相加。本节尚不证明所有候选分解方式都与旧基线等价；无合格 z 的分量保留原所有权 / 本地路径。

**B. 前缀覆盖与初始化。** 令 A_i(u)=1 表示该前缀属于来源生成器的真实可达域：必要源状态已知，分支及其辅助采样有效，能够在普通终止规则和正 RR 存活下到达按 A 节选定的 z。令 G_P,i(y) 为相容可逆前缀图表及源 / 目标首次资格规则检查，u_i=T_P,i^{-1}(y)。则可用的部分映射支持为：

$$
\chi_{P,i}(y)=A_i(u_i)G_{P,i}(y).
$$

到 z 的缓存是否命中不进入 A_i；所以 z 查询失败的 BSDF 回退和查询成功的缓存分支共享这一前缀域。A_i 和 G_P,i 必须由实际采样 / 重放规则和来源上下文落实，不能从赢家标签猜测。必要状态未知时，只在已认证的部分域内复用；域外由新鲜来源覆盖。

采用主采样空间的前缀测度 mu_P,i，实际方向 / 分支密度留在约定的 F / 映射中。令 R_P,i(u)>0 为到 z 已发生的 RR 存活概率乘积，登记 W0=1/R_P,i。RR 失败贡献为 null 且不补抽，在该前缀域上：

$$
\mathbb E[W_0 g(U)]
=\int_{S_{P,i}}R_{P,i}(u)\frac{g(u)}{R_{P,i}(u)}\,d\mu_{P,i}(u)
=\int_{S_{P,i}}g(u)\,d\mu_{P,i}(u).
$$

这给出前缀加权覆盖，与 z 后的尾部亮度 / RR / 缓存命中无关。初始前缀压缩再按真实选择概率补偿即可保持该式；必须给合法零尾部前缀正的选择机会。D/S 各自在自己的确定通道内推导，不额外除 2。

**C. 完整 BSDF 域还要包含来源是否实际续接。** 定义 e_i(u)=1 为来源上下文在 z 的实际合法缓存终止决定，成功且 RGB=0 也为 1；e_i=0 时才在 z 进行普通 BSDF 尾部生成。数值异常不混入正常命中 / 未命中的证明。对完整事件 x=(u,v)，设 Gamma_B,i(x) 包含原版完整事件的可生成 / 可选支持、合法后缀图表、分支 / PDF / 灯事件匹配及固定尾部依赖有效性，则：

$$
\chi_{B,i}(x)=\chi_{P,i}(u)\,[1-e_i(u_i)]\,\Gamma_{B,i}(x).
$$

该式针对来源整个加权生成 / 复用过程，不针对当前保存记录是否恰好携带尾部。Gamma 必须保留原 BSDF 事件所需的全部条件；不能只检查 z 的命中就忽略更深终止和模型依赖。冻结且已知规则状态下，可在来源几何 / 方向上下文恢复 e_i 并执行已有接缝检查；新鲜来源在当前 e_t=0 的有效 BSDF 域提供 canonical 覆盖。来源 e_i=1 而当前 e_t=0 时，该来源的完整事件项为零，新鲜 m_B=1；其前缀 m_P 仍可非零。

**D. 一个此前遗漏的单 W 充分条件。** 仅在 pi 中混入正前缀提议，不能修复 m_P 自身为零。若同一候选 chi_P,C=chi_P,H=1、m_B,H=1/2，而纯缓存亮度代理为 P_C=1、P_H=0，则 m_P,H=0。即使 pi_H>0，也会得到 W'_H=0，同时尾部更新要求除以 m_P,H，有限 RGB 无法表示该贡献。只对全零分母回退不会发现这个反例。

该反例说明原计划尚未证明两个评分零集的兼容性，不等于已在当前 GPU 配置发现相同故障。因此本次选择一个充分的修正：前缀分配先取 P_P,i=1；引入当前缓存代理时按第 5.5.3 节使用带正值底项的代理。代理只依赖前缀与固定 / 合法条件化上下文，不依赖随机尾部补偿。由 chi_B,i>0 蕴含 chi_P,i>0，加上正 eta 和有限正反 J，可得：

$$
m_{B,i}>0\ \Longrightarrow\ \chi_{B,i}=1
\ \Longrightarrow\ \chi_{P,i}=1
\ \Longrightarrow\ m_{P,i}>0.
$$

再用第 5.3.3 节正前缀抽选提议保证所需 pi_i>0。这是对每个合法来源的正支持要求，不只是对整组候选的分母非零要求。物理输出 F 不添加正值底项。该充分条件保障表示 / 覆盖兼容，不自动继承原版完整事件的方差或渐近收敛界，也不保证更低 GPU 成本；极端 W / RGB、方差和成本仍须独立验证。

**E. 两个不变量与任意有限轮归纳。** 假定输入前缀满足 B 节积分式，输入有效 BSDF 事件存在与带补偿 RGB 等价的原完整事件 oracle V_i / I_i，并满足相应来源域的有效贡献权重条件；无有效尾部时完整事件取 null，前缀仍可有效。两种 Shift 的投影相容，m_P 是前缀函数，m_B 在同一完整事件上形成有效分区，pi 在所需项上为正。对任意固定前缀测试函数 g，条件于本轮输入记录：

$$
\mathbb E_{\rm select}[W'g(Y)]
=\sum_i m_{P,i}(Y_i)W_i|J_{P,i}|g(Y_i).
$$

再对输入取期望、按有效部分映射换元并用同一 y 上 sum_i(m_P,i)=1，得到目标前缀域的 integral(g)。这一步无需假设不同来源样本互相独立；但来源权重与评分所依赖的上下文必须满足本节前提。

BSDF 赢家用同一次选择更新 W 与尾部，线性局部评价下逐样本有：

$$
W'\mathcal E_{B,t}(\widetilde I')
=\frac{m_{B,k}V_k|J_{B,k}|}{\pi_k}\mathcal E_{B,t}(I_k).
$$

对选择取期望，pi 抵消；再用源完整事件权重、J_B 换元和 sum_i(m_B,i)=1，得到当前 BSDF 完整事件的积分。单个输入尾部的共同正缩放在 Talbot 比例中抵消，因此这项分配不能任意依赖此前的随机 RGB 补偿；零缩放 / null 按独立分支处理。由此避免把前缀 W 与任意条件尾部权重直接相乘。

令 C_t(u) 为当前缓存的前缀求值，B_t 为当前 e_t=0 的完整事件域，唯一归属下的目标是：

$$
I_t=\int_{S_{P,t}}e_t(u)C_t(u)\,d\mu_{P,t}(u)
+\int_{B_t}f_{B,t}(x)\,d\mu_{B,t}(x)+I_{\rm other}.
$$

缓存项由前缀不变量得到；BSDF 项由完整事件不变量得到；z 前及无 z 等其他分量维持原所有权。这里目标是同缓存近似下的基线估计器，不是证明 SHaRC 等于真实无缓存光照。两不变量在本轮输出成立后，下一轮继续用同样规则，即可归纳到任意有限轮；前提改变或历史失效时，须先恢复合法输入域，不能用该归纳证明任意在线变化。

一个单前缀例子：输入 W_C=W_H=1、J_P=J_B=1，m_P,C=m_P,H=1/2、pi_C=pi_H=1/2。历史来源在 z 缓存终止，当前来源须 BSDF 续接且尾部贡献为 10，故 m_B,C=1、m_B,H=0。选当前时 W'=1、尾部变为 20，输出 20；选历史时 W'=1、没有 BSDF 尾部，当前物理输出为 0。期望为 10，前缀加权质量为 1。下一轮若当前 z 合法缓存值为 7，则两种前缀均可按 W' 查询得到 7，不需要恢复已丢弃尾部。

**F. 不能从现有单条记录恢复任意历史终止域。** 构造 A/B 两个等概率前缀，历史实际抽中 A；两种历史状态在 A 的缓存、所存 W=2、类型、F 和路径字段完全相同。只在未抽中的 B 上令状态一 e_H(B)=0、状态二 e_H(B)=1。以后当前缓存状态和当前 BSDF 候选 B 也相同。两份可见历史记录无法区分，但完整事件支持分别要求 chi_B,H(B)=1（另满足 Gamma）和 0。因此不存在只读取这一条记录及当前缓存，就能对任意历史缓存变化精确重建 e_H 的通用判定函数；W 的数值和历史赢家类型均不能补回缺失的信息。

可用的处理范围由此明确：冻结 / 已知支持状态下直接执行 C 节判定；一般在线时，须有足以重建 e_i 的来源终止域信息，或来源规则在该候选上未变的可靠证据。没有证据时，将该完整事件来源的允许映射域收窄、令历史 m_B=0，由 canonical 新鲜来源补齐；该决定必须是同候选、同源上下文的一致规则，不随历史赢家是否有尾部而改变。在 A/B 节前缀条件仍成立时可以继续保留历史 m_P，用于当前缓存求值；仅缺少 z 处的历史 e_i，不应无故把仍可认证的前缀历史全部清空。不能把保守丢弃完整事件误写成证明真实来源概率为零。不要求保存旧缓存 RGB 或整份旧缓存，但也不能凭当前查询成功消除这个信息边界。该方案可保留受支持区域的 SHaRC 前缀复用，但不得把未知 e_i 区域的 fresh-only BSDF 贡献宣称为完整 BSDF 时间复用收益。

**G. 本次受控精确枚举与仍未完成的范围。** 使用 A/B 两个前缀、各一个固定 BSDF 尾部，B 值为 (10,18)、缓存值为 (7,9)，eta_C=1、eta_H=3。初始历史的前缀测度为 (2,1/2)、完整事件测度为 (3,1/4)，目标测度各为 (1,1)，故同时覆盖非单位 J_P、J_B 及其差额。缓存终止掩码从 (1,0) 依次变为 (0,1)、(0,0)、(1,1)、(1,0)，每轮真实选择概率 pi_C 分别为 2/5、1/3、7/10、3/5。用精确有理数在内存枚举各轮 8、32、128、512 个输入 / 选择分支，前缀质量每点均为 1，输出逐点分别为 (10,9)、(10,18)、(7,9)、(7,18)。旧掩码由夹具明确提供，不声称已经从现有 GPU 记录恢复。

该非单位测度夹具按已知源测度 / 采样概率构造有效输入权重，专门检查换元、两个 J 的差额和抽选补偿，不代替 B 节的实际 PSS / RR 初始化验证。额外检查了历史只覆盖 A 的部分域、零 BSDF 尾部转为正缓存值，以及错误地按历史实际赢家是否有尾部判断来源支持。后者在一组两轮夹具中将 A 的期望由 10 错算为 16，精确枚举检出了错误。上述是本次推导的有限模型核算，未新增临时脚本文件，也不是 tests/RTPT 正式测试、Slang / GPU 验证、统计画质或性能证据。

据此，缺①得到 A/B 节收窄规则下的条件推导；缺②得到 C/F 节的判定式、所需来源信息和无法精确判定时的合法部分域回退；缺③得到 E 节在明确假设下的任意有限轮归纳及 G 节有限夹具检查。尚不能宣称任意选点 / 材质 / 场景变化、现有紧凑字段或完整在线来源状态已满足全部假设。实际选点与旧基线贡献归属、分支 / 重放状态充分性、一般在线来源域信息及问题④仍需落实；阶段 3–9 依旧未实施。

- 在新模式定义 BSDF、NEE、RR、reservoir、训练 / Probe 随机流及重放 recipe。若拆分原 sg，作为本阶段单独变化验收，不能继续要求与旧轨迹逐位相同。
- 按第 5.4.5 节定义共用前缀头和两种尾部负载：真实 z、根标签、实际分支、深度、必要前缀 seed / checkpoint、来源连接 PDF / 几何、单个 W、M、F 和独立有效性标志。BSDF 保留方向、PDF、灯 / 事件信息；SHaRC 不增加尾部方向 / 随机流或旧缓存状态。
- 定义不依赖尾部亮度 / 缓存成熟度的前缀锚定规则、z 前 / 后贡献分区和旧历史格式失效。确认原 BSDF 求值对尾部 RGB 线性，明确所有要统一缩放的项；本阶段只定义 / 验证因子与布局，初始尾部打包和 RIS 在阶段 4 实现。
- 事件直接求和，尚不做 RIS。明确最大路径长度编码，不能照搬参考实现 4 bit / 15 跳上限。
- 按第 5.5.6 节 A/B 核对“首个结构合格表面”选点的实际贡献归属、全部辅助随机状态及源 / 目标首次资格检查；将其与已有 Generate 对应后才可使用本节前缀证明。无法对应的事件仍走原所有权，不根据缓存成熟度临时改 z。

**验收目标**
- 局部采样：分支频率与 alpha_l、分支条件方向统计与 p_l、联合统计与 q_l 一致；sum_l(q_l) 与实际混合方向 PDF 一致，失败 / null 质量纳入总分布，评价确定性有证据。不能仅用两个 PDF 接口数值相等代替采样分布验证。
- 固定实际分支和方向时，B_l 与旧 bs.weight 在数值容差内一致，覆盖不同分支概率、极弱分量及 activeLobes 配置；没有重复除 alpha_l。改变连接条件后重新评价目标分支，不能沿用来源数值。
- 在 SHaRC off 配置下，新分支评价无 RIS 基线相对旧无 VXPG 基线，D、S、总 HDR 的均值通过等价协议；若更改随机流，单独记录该因素。缓存开启时的新旧基线另在阶段 6A 比较，不由本项自动推定。
- 身份重放恢复同一事件、命中身份、采样参数、终止、前缀 R_P / 临时事件 R_j 和贡献；改变诊断 / 选择随机流不改变前向路径。缓存后尾部字段不作为重放前缀的隐含依赖。
- 事件提取后直接求和与新基线逐样本一致；每项已发生 RR 只补偿一次。前缀头与尾部字段清单可恢复所需状态，没有新增 U / V / rho 持久化字段，不绑定旧 188 B 布局。
- delta、alpha test、掠射角、法线贴图、粗糙度边界、极弱分量有明确支持 / 回退结果。
- previousDiffuse 等辅助状态能从保留的分支正确恢复；不通过混合 K / p_mix 偷换前向缓存分区。缓存终止的联合验证留给阶段 6，不宣称已支持缓存复用。

**进入下一阶段条件：**新基线正确、事件描述足以自重放。若新旧均值不等价，先定位材质 / RNG / RR 差异，不能让 NRD 掩盖。

### 阶段 4：初始单前缀 reservoir 与 BSDF 尾部初始化

**目的：**只验证“多个贡献选一个”本身不改变期望。

**实施与交付**
- 到 z 时先建立 W0=1/R_P；在同一前缀的普通 BSDF 尾部事件内求临时 V0，再写 I_tilde0=(V0/W0)*I0。多个前缀压成每像素一个带根标签的 reservoir，采用真实 pi 及原贡献系数；不新增 U 或尾部独立 W。
- 实现第 5.2 节的 W / I_tilde / F、完整像素批次 M=1、正前缀提议、空集合与有效零前缀；改写旧 Finalize / 亮度清零语义。V0 只在生成或测试 oracle 临时使用。
- 首先在 SHaRC off 配置验收；完整缓存事件的初始选择归阶段 6A。
- 提供事件直接求和与 Initial-only 两种明确诊断路径；关闭 Temporal / Spatial 是合法可运行组合。

**验收目标**
- 固定候选池上的选择频率、C/pi 和 D/S 条件期望与解析值一致。
- 单前缀、无 RR 时 W0=1；到 z 的存活概率为 R_P 时 W0=1/R_P。每个合法尾部事件满足 W0*E_B(I_tilde0)=V0*E_B(I0)，尾部 RR 不再次进入 W。
- 无合法前缀为空集合；合法前缀但全零尾部 / 尾部 RR 死亡时，F=0 而 W 与身份仍可有效，正提议能选中并保留它，不补抽、不计算 0/0。稀少有效事件不被额外除次数。
- D/S 两路数、事件数、历史 M 均未重复归一化；没有因低成功率重抽。
- 对独立运行，Initial-only 相对事件求和的 D、S、总 HDR 均值等价。
- 两路差异极大、某通道零贡献、NEE off、各灯类型及资源失败恢复都通过。
- 解析夹具 A=(2,8)、B=(6,14)：原完整事件对照和 W*带补偿尾部的初始均值均为 30。假想积分尾部改成 A=12、B=9 时，前缀加权期望为 21；本阶段只做有限模型，不声称 SHaRC 渲染已接入。
- 新模式 records / bank 大小和首次生成射线数已记录；一个持久化 W，没有独立 U / V / rho，旧格式历史按版本失效；不把 winner 数当成候选追踪成本。

**进入下一阶段条件：**初始压缩无新增可测能量偏移。它本身还不是完整 GRIS 接入。

### 阶段 5：普通 BSDF 空间复用与 Hybrid

**目的：**在无缓存、冻结灯分布条件下先解决路径搬移。

**实施与交付**
- 5A：先限制在已验证连续粗糙连接，固定真实锚点，少邻居、一轮空间复用。
- 5B：增加必要前缀随机数重放 + 固定接缝的 Hybrid；保持已保存尾部，重算局部 BSDF / PDF / 可见性，不执行 z 后完整重放、重新采样或 traceTemporalUpdate。
- 5C：覆盖 Grid / Global、面积灯、解析灯、环境与必要灯映射。Tile 只验证首表面保留项，不扩大为次反弹采样。
- 按第 5.5.4 节的问题③确定策略，分别实现完整事件 m_B / J_B 与前缀 m_P / J_P 的有效域 Shift 和 Talbot 交叉评价；不支持来源项归零后统一分配，按第 5.3.2 节更新 W 及尾部 RGB，保持同一赢家。保留根标签、分支及 canonical 新鲜覆盖，多轮使用独立 bank。
- 使用真实 pi 的正支持提议，不把旧 sum(a_B)/h(F_B) 当作前缀 W。先以输入负载完成所有评价，再给赢家乘差额、同步 F 与来源 PDF / 几何；不能把完整 J 的尾部部分既乘进 RGB 又在输出外乘一次。
- 冻结尾部依赖，建立场景 / 光照 / 材质及实际尾部模型依赖的失效规则；变化后丢弃受影响历史，由新路径补充，不用重追尾部掩盖不支持。
- 对 delta 链、不支持连接及零目标明确 partial mapping / 本地所有权，保留真实贡献。

**验收目标**
- 分别验证 J_P、J_B 的 identity / 正反恢复与互逆，适用连续域上与独立解析 / 数值样例一致；m_B 与 m_P 不同或 J_B/J_P 非单位时，仍逐样本满足原完整事件贡献恒等式。
- 每个目标测试路径上的 sum_i(m_i)=1，不支持来源的 m_i=0；仅新鲜来源支持时 m_0=1。覆盖来源赢家标签与被交叉评价路径标签不同的情况，不能用赢家身份替代来源支持。
- 合并分数与新 finalize 不重复乘 / 除 M、邻居数；固定小型候选域的解析积分与重采样条件期望一致，验证两种域的反向 J / 来源 self 项与各自 forward J 换算，不能混用完整 J_B 与前缀 J_P。
- 对同一 BSDF 候选跨来源使用相同输入尾部缩放：线性亮度下 Talbot 分配与未打包对照一致；乘差额后的 F、self 项与下一轮负载保持同步。
- 无邻居退化正确；重复来源、零贡献来源、多轮复用不造成系统性增亮 / 变暗。
- 薄几何遮挡、近场、遮挡变化、背面、无可连接点和根 lobe 不匹配，不漏本地贡献。
- 真实可见性由 RayQuery 验证；每轮读取旧 bank，重放不写训练 / 选灯反馈。
- 各灯测度正确，samplePdf 与 misReferencePdf 分工明确。固定灯点与随机数重放终点变化的规则分别通过。
- 至少两轮、多个前缀的有限枚举同时保持前缀加权积分与 BSDF 完整事件积分；4 个初始事件的两轮枚举应覆盖全部输入 / 选择分支，BSDF 均值为 30，不能只展示一条赢家路线。
- 统计首次生成、前缀恢复、连接可见性与旧尾部射线：旧尾部重放 / 更新射线和随机数消费为 0，不把连接射线算成尾部重追；尾部 seed 扰动不影响纯局部重连。
- Spatial on/off 的 D/S/总 HDR 均值等价；同时记录极端 W / 尾部 RGB、有效映射率、各类射线和 GPU 成本。

**进入下一阶段条件：**5A、5B、5C 在申明支持域内分别通过。只做易场景直接重连不能宣称完整 Hybrid 已完成。

### 阶段 6：完整 SHaRC 缓存事件接入

**目的：**复用到达真实缓存点的路径前缀，不引入 PG 配对机制。

**实施与交付**
- 6A：先独立预热完整缓存，再冻结且继续查询；分别检查旧 BSDF / 新分支评价基线的均值、缓存事件提取与 Initial-only。Freeze 不等于 Use cache=False，空缓存不能冒充有效缓存对照。
- 6B：同一冻结状态下空间复用，按第 5.4.1 节实现缓存终点 J、按第 5.3 节实现 Talbot 分配；按第 5.4.4 节恢复当前 p、z，检查可见性与资格，并直接从 z 查询当前缓存，不用缓存编号作为路径身份。
- 6B：落实问题①的终点表示和第 5.4.5 节字段：SHaRC 只使用共用前缀头与终止类型，不生成或读取 z 后的方向、几何、PDF、随机流或虚拟点。p 变化后按新 sd.V 查询并恢复材质；普通 BSDF 继续读取已有方向 / PDF 与带补偿尾部 RGB，不重追其旧尾部。
- 6B：以有效的新格式前缀 W 支持 BSDF → SHaRC：丢开旧尾部负载及其补偿，F 改由当前查询产生，J 仅为 J_P；不把 W 重置为 1、不乘旧 / 新亮度比，不新增 U。旧格式完整事件历史按版本丢弃，不进行事后转换。
- 6C：恢复独立更新 / Resolve，仅做同帧复用，发布后帧内只读；Generate、shift、反向求值和 Final Resolve 读取同一状态。动态缓存的时间复用按第 5.5 节在阶段 7 验证。
- 生成、重放和重连均保留第 5.1 节要求的采样分支，沿用既有 previousDiffuse / footprint 资格；目标条件变化时重新判定，不将终止域改成与分支无关的近似规则。
- 按第 5.4.4 节区分几何 / 映射失败、遮挡、资格失败、缓存缺失、未成熟、有效零值及数值异常，并记录尝试数和各结果数。新鲜路径查询失败继续真实追踪；复用候选失败不沿用旧 RGB、不临时延长后缀、不补抽，支持和 m 按同一规则处理。
- 不用 GRIS winner 或 NRD 输出回灌 SHaRC；不为重放重复训练。
- 验证第 5.5.6 节的结构选点与尾部唯一归属：z 查询失败后的真实续接可在更深处终止，但不能既计完整尾部又重复加入更深缓存项。先用 P_P=1，再验证带正值底项的缓存代理；分别记录 m_P 与实际 pi 的支持，不把两者混同。
- 核对训练与渲染 / reservoir 随机流，以及经 Grid / Tile 等反馈产生的间接依赖；按固定或条件化模型状态检查来源贡献权重的有效性。独立 seed 和 GPU 同步均不单独构成该条件的证明。

**验收目标**
- 6A：先对同一冻结缓存比较旧普通 bs.weight 路径与新分支评价无 RIS 路径的 D/S / 总 HDR 均值，并在固定随机序列的适用测试中比较分支、资格和逐事件贡献。若不等价，先检查 K_l/q_l、分支状态、RR 与资格恢复，不能只禁止 shift，也不能把差异直接归为缓存固有误差。
- 随后要求原始事件直接求和与新无 RIS 缓存基线逐事件一致；带补偿初始路径以 W*F 检查均值与初始化恒等式，不能要求其存储 RGB 与未打包事件逐值相同。这两步不能替代上一步的新旧缓存基线检查。
- 上述对照同时固定灯分布与场景，记录各 lobe 条件下的缓存终止率和贡献，避免总 HDR 偶然抵消掩盖分量差异。
- 6B：identity / 正反 / J / 遮挡通过；重连保留采样分支，但目标 alpha_l、方向密度、距离或 footprint 可变化，必须重新评价权重及资格。无对应分支时按支持规则处理，不能改分支继续沿用 W。
- 6B：缓存终点使用 J_P=(q_t/q_s)*(G_t/G_s)，没有终点出射 PDF、重复 BSDF 或旧尾部差额；更早普通锚点的保留因子仍进入正确映射。验证目标 q 的抵消、几何法线、材质恢复、逐路径 sum(m_P)=1 和新鲜独占区域。普通 BSDF 的 J_B/J_P 差额仍只作用于其尾部负载。
- 6B：检查终点记录与执行：缓存成功后没有 z 处继续 BSDF / NEE / RR、尾部射线或尾部随机数消费。若共享布局保留无效槽位，仅扰动明确属于 z 后且不参与前段重放的字段，当前 F/J 和选择结果必须不变；普通 BSDF 路径使用的有效字段不能被误删。
- 6B：固定 z 与当前缓存，改变前一点 p→p′，核对新的 sd.V、查询资格、材质恢复以及 beta_t * L_cache,t。源 / 目标仍在有效域时，J 与源 / 目标连接 PDF、几何比一致，通过 identity、正反互逆及独立数值样例；无 z 出射 PDF 比、BSDF 比或缓存亮度比。缓存 RGB / 材质恢复变化而几何和前段采样密度不变时，允许 F 改变，但 J 不应因缓存亮度改变。
- 6B：分别检查纯漫反射与合格的光泽查询，同缓存、同观察方向下与无 GRIS 基线比较；当前非方向编码缓存的高光方向近似另与无缓存参考量测，不把 J 正确视为完整方向光照已恢复。
- 缓存成功时端点贡献不重复；缓存失败由当前新鲜路径承担真实续接，旧缓存历史不延长尾部；合法零值不是查询失败，不重抽。有效黑色前缀在正提议下仍有加权覆盖，W 不因 F=0 被抹掉。
- 用原 GRIS 方向 / 尾部字段的新 BSDF 记录经过至少两轮后转换为 SHaRC，验证普通贡献仍等于完整事件对照，转换后只用前缀 W。有限夹具 BSDF=30、缓存 A/B=12/9 时结果=21；故意沿用旧完整 V 或尾部差额的实现应被检出。
- 字段扰动：SHaRC 类型改变未使用 rcVertexWi、尾部 RGB、z 出射 PDF、lightPdf 或尾部 seed 不影响 F/J_P/W；BSDF 类型的有效负载则必须影响对应求值。共享布局允许无效槽位，不允许读取依赖。
- 6B：固定 z 的几何与当前查询状态，修改可选查询提示或缓存存储槽位不得改变结果；可恢复的真实表面身份是依据。验证 p→z 遮挡、其他保留路径段遮挡和前缀提前终止，不能只测试最后一段。
- 6B/6C：用可控用例覆盖条目缺失、样本数未达成熟阈值、footprint / 深度 / 材质资格失败、成功且 RGB=0，以及非有限数据。候选评分、失败原因、新鲜路径续接与贡献所有权分别符合第 5.4.4 节，不以“多数时候成功”代替这些用例。
- 6C：物体移动、当前 LOD 改变或槽回收后，从恢复后的 z 重新定位缓存，不误读旧槽；记录实际失败率、有效零查询率、缓存命中率、额外射线数及当前查询成本。
- 深度、roughness、delta、发光、成熟度、LOD、槽回收、Clear、Freeze/解冻、Enabled/Use cache 均覆盖。
- 6C：同帧版本一致、无读写竞争；正常在线更新与冻结状态分别报告结果。同帧 Spatial on/off 在相同缓存估计目标下通过均值协议，并提供训练 / 反馈依赖核对结果；相关性本身不直接判错，但必须说明条件化权重为何仍适用。
- 一组对照量测“GRIS 相对同缓存基线”的新增误差，另一组量测“缓存相对无缓存参考”的近似误差，二者分开。

**进入下一阶段条件：**完整缓存的生成、初始选择、空间映射和帧内状态分别通过。在线依赖若未满足所选权重条件，必须记录限制，不能把 barrier 或独立 seed 当作无偏证明。

### 阶段 7：时间复用与动态状态生命周期

**目的：**在模型与光照变化时复用路径，而非积累旧颜色。

## 7. 全阶段统一验收协议

### 7.1 四种对照，不能混用

1. 结构等价：旧路径与仅拆分管线后的路径，同状态同随机序列逐样本比较。
2. 估计器等价：旧 bs.weight 与新分支评价比较固定分支下的权重，再比较无缓存 / 冻结缓存的 D/S 统计均值；若改动随机流，单独记录，不能把分支计权错误归为随机差异。
3. 重采样等价：事件求和、Initial、Spatial、Temporal 在同一新估计器及相同模型状态下比较。
4. 整体画质 / 成本：无缓存参考、相同缓存基线、完整新管线分别测量；NRD 和最终累积另开关比较。

### 7.2 数值与统计判据

- 身份重放的离散身份、事件标签、计数应精确匹配；浮点采用阶段 1 固定的绝对 + 相对容差。容差须注明 HDR 尺度、近零处理与编码差异。
- 能量等价使用独立 seed 的 D、S、总 HDR 及预先指定 ROI 差值；建议采用 99% 置信区间，要求区间整体落在预登记等价带内。
- “差异不显著”或“置信区间覆盖零”不能当作等价通过。低亮度采用绝对误差，普通区域采用相对误差；多区域比较使用预定义的同时判据。
- 使用独立 pilot 确定固定采样预算 / ROI / 容差。正式结果不足以判断则标 inconclusive；不能删 seed、换 ROI、放宽阈值或不断追加直到通过。
- 无 NaN / Inf、未初始化访问、资源越界和负概率；合法零事件、极小正概率与数值异常分开统计，不能用 clamp 将错误隐藏。
- 可见性、主命中、缓存资格和正反映射采用有意义的边界案例；不只写与实现一模一样的自证测试。

### 7.2.1 单前缀 W 的专项验收协议

按阶段逐步实现以下检查，不能以文档中的恒等式或对话内有限枚举代替正式测试 / 渲染证据：
1. 初始化与 RR：验证 W0=1/R_P，I_tilde0=(V0/W0)*I0；前缀 RR 失败无样本，尾部 RR 死亡保留有效前缀。单候选无 RR 退化 W=1；尾部补偿只进入 RGB 一次。
2. 原完整事件 oracle：仅在 CPU / 测试诊断临时维护 V 与原 I，逐 RGB 分量比较 W*E_B(I_tilde) 与 V*E_B(I)。正常 GPU 历史不增加 U、V 或 rho 字段。
3. 逐轮恒等式：分别改变 m_B/m_P、J_B/J_P 和真实 pi，覆盖非单位比值、不同来源、极小正概率及至少两轮；确认同一个赢家携带完整前缀 / 尾部，F 与全部 RGB 项同步更新。拒绝 m_B>0 且 m_P=0 等不兼容域，而非 clamp。
4. 有限积分与多前缀：A=(2,8)、B=(6,14)，初始概率为 (2,8,6,14)/30，前缀 W 为 (3,3,1.5,1.5)，对应打包 RGB 为 (10,10,20,20)。在 J=1 的离散模型中枚举一轮 32、两轮 256 个输入 / 选择分支，前缀加权质量 A/B 各为 1，完整事件加权质量四点各为 1，BSDF 均值为 30。来源 m_B 须针对同一事件形成分区，不能按两个实际赢家临时归一化。
5. SHaRC 转换：保留上述前缀 W、丢开尾部后，缓存 A/B=(12,9) 的期望为 21；故意用完整 V 会得到错误结果，测试必须能区分。固定尾部 / PDF，只改缓存值时 W 不按亮度重建、J_P 不变；F 与最终期望响应当前查询。
6. 零值与支持：构造整个前缀的 BSDF 尾部为零、无尾部事件、成功且黑色缓存、缓存缺失 / 未成熟等不同状态；正提议使合法零前缀仍有覆盖，不补抽。按第 5.5.4 节的确定策略验证有效域内评分、域外零项及双方分母一致，覆盖 2 / 6、2 / 0 夹具和期望 2 而非 1.5 的支持反例；正提议不能代替其余来源域检查。 另按第 5.5.6 节独立检验 m_P=0 而 m_B>0 的表示失败，分别验证正前缀分配代理与正抽选提议。将 G 节受控四轮及错误赢家标签使 10 变 16 的夹具纳入未来正式测试，不把本次内存核算记为正式测试通过。
7. 交叉评价与 F：共同正尾部缩放下，完整 BSDF Talbot 的同候选评分比例保持；所有来源使用同一输入负载。更新尾部后存储 F 同步，SHaRC 类型扰动未使用尾部字段无效；M 不重复归一化。
8. 射线与资源：首次生成尾部、必要前缀重放、连接可见性分别计数；复用阶段 z 后旧尾部重追 / 更新射线与 RNG 消费均为 0。旧格式版本不能继承；普通相机运动不因“单 W”无故清空合法历史。
9. 数值门限：上述有界有限夹具先用解析 / FP64 oracle，绝对容差 1e-10、相对容差 1e-12；对应 GPU FP32 夹具为绝对 1e-5、相对 1e-5（按 absErr <= absTol + relTol*abs(reference) 判定）。实际 HDR 的统计等价带、ROI、预算仍由阶段 1 预登记，不能沿用小夹具门限代替统计协议或为通过而放宽。首版使用可审计 FP32 尾部负载，报告极值 / 非有限值，不以额外 clamp 消除差异。

若某项仅在冻结状态或受限材质 / 连接域内通过，应明确该范围；在线缓存、Grid 反馈及动态支持仍须满足第 5.5 节条件，不从这些有限夹具推定全局无偏或运行验收通过。

## 9. 已确定方案与尚待验收的关口

**问题①的表示已确定：**SHaRC 在真实 z 终止，没有 z 后的 BSDF 方向、几何、PDF 或辅助随机流；当前方向的材质恢复进入 F，缓存 J 只采用实际前缀 / 连接的 J_P。

**问题②的记账方案已确定：**第 5.2 / 5.3 节采用单个持久化前缀 W，不新增 U。普通 BSDF 保留原 GRIS 尾部字段，将完整事件相对前缀的补偿吸收进 RGB，每轮按 m_B/m_P 与 J_B/J_P 更新；只恢复必要前缀并局部重连，不重追旧尾部。有效新格式 BSDF 前缀可转换为当前 SHaRC 查询，转换不携带旧尾部差额；旧完整事件格式须失效。初始化、逐样本等式与多轮有限目标已经明确，但尚未实现或通过 GPU / 渲染验收。

**问题③的处理策略已确定，并补充了条件推导：**第 5.5.4 节采用原版 GRIS 的有效映射域、双向 Shift 交叉评价与 Talbot 分配。第 5.5.6 节给出结构选点下的 chi_P、带来源终止因子的 chi_B、单 W 正代理的充分条件及两不变量的有限轮归纳，完成受控四轮有理数夹具核算。也给出单条记录不能恢复任意历史终止域的反例；未知域采用一致部分映射回退，而不宣称所有在线域已判明。实际选点 / 贡献归属与字段充分性、来源域信息、适配实现及 GPU 验收仍待完成。阶段 3–9 未实施，问题④仍按第 5.5.5 节单独验证。

下列仍是必须按阶段留下证据的关口，不将“方案选定”写成“算法已通过”：
- 阶段 1 / 3：前缀 / 尾部唯一归属、指定 z 的规则及其与旧缓存基线的等价，分支联合密度、null 质量、R_P / R_j 时序与前缀记录充分性。

- 阶段 6：单 W 下的 BSDF → SHaRC 转换、当前 z 字段与失败规则、冻结缓存均值及方向近似边界；有限补偿恒等式不修复缓存近似。
- 阶段 7：验收问题③已选定策略的 chi_P / chi_B 有效域检查、当前代理一致性、各域分区与多轮贡献；另验收问题④的在线训练 / 反馈条件。正前缀提议解决一类零亮度覆盖缺口，不能代替动态历史支持的可靠判定；不预设旧缓存快照。
